# Higgsfield 이미지 모델 가이드

Higgsfield MCP가 노출하는 이미지 생성 모델 5종의 강점·약점·권장 프롬프트.

## 1. Soul (Higgsfield 자체 모델) ★

**강점**:
- 시네마틱 그레이딩·필름 룩
- 캐릭터 일관성 (custom_reference_id 지원)
- 인물 표정·디테일 정교
- 한국어 프롬프트 이해도 높음

**약점**:
- 글자 렌더링은 Nano Banana보다 약함
- 추상적 일러스트는 Seedream이 더 적합
- 크레딧 소비 다소 높음

**권장 시점**:
- 인물 시리즈·브랜드 캐릭터
- 광고 키 비주얼
- 발표 슬라이드 표지 이미지
- 캠페인 마스코트

**예시 프롬프트**:
```
한국인 30대 여성 CEO가 회의실에서 노트북을 보고 있다.
부드러운 자연광, 시네마틱 그레이딩, 미니멀 인테리어,
포커스는 인물에. 16:9 와이드샷.
```

```
30s Korean female founder, looking at laptop in modern office.
Cinematic grading, natural soft light, minimalist interior,
focus on subject. 16:9 wide shot.
```

## 2. Nano Banana (Gemini 3 기반)

**강점**:
- **글자 렌더링 SOTA** — 카드뉴스·포스터·인포그래픽
- 2K 해상도까지 지원
- 다양한 폰트·레이아웃 표현
- 비교적 빠름

**약점**:
- 시네마틱 톤은 Soul보다 약함
- 인물 일관성 시리즈에 부적합
- 사진 사실성은 Flux보다 약함

**권장 시점**:
- 카드뉴스 4-10장
- SNS 인포그래픽
- 포스터·배너
- 글자가 핵심인 비주얼

**예시 프롬프트**:
```
인스타그램 카드뉴스 1장. 1:1 비율.
헤드라인: "5분 만에 끝나는 AI 영상 편집"
크림 베이지 배경, 오렌지 포인트 컬러,
Pretendard 굵은 헤딩, 한국어 가독성 우선.
```

## 3. Flux

**강점**:
- 사진 같은 사실성
- 제품·풍경·자연주의 톤
- 디테일 정밀도 최고
- 조명·재질 표현 정교

**약점**:
- 인물 표정 디테일은 Soul보다 약함
- 시네마틱 그레이딩 부족
- 글자 렌더링 약함

**권장 시점**:
- 이커머스 제품 샷
- 풍경·자연 사진
- 음식·인테리어 사진
- 사진 합성 결과물

**예시 프롬프트**:
```
프리미엄 가죽 지갑, 흰 배경, 부드러운 측면 조명,
디테일이 살아있는 가죽 질감, 깔끔한 그림자.
정사각 1:1, 이커머스 상세페이지용.
```

## 4. Seedream

**강점**:
- 다양한 스타일·실험적 톤
- 일러스트·아트워크
- 색감 대담한 표현
- 추상·상징적 비주얼

**약점**:
- 사실성은 Flux보다 약함
- 인물 일관성 약함
- 글자 정확도는 Nano Banana보다 떨어짐

**권장 시점**:
- 마케팅 비주얼 (대담한 톤)
- 아트워크·NFT
- 일러스트 카드
- 캠페인 무드보드

**예시 프롬프트**:
```
추상적 일러스트, 미래 도시의 야경,
사이버펑크 톤, 네온 핑크·블루 그라데이션,
영화 같은 분위기.
```

## 5. Cinema Studio

**강점**:
- 영화 필름 그레이딩 전문
- LUT·컬러 사이언스 모방
- 핸드헬드·트라이팟·돌리샷 시뮬레이션
- 광고 키 비주얼 톤

**약점**:
- 일러스트·만화 톤 부적합
- 글자 정확도 떨어짐
- 크레딧 가장 비싼 편

**권장 시점**:
- 광고 키 비주얼
- 영상 썸네일 (Veo·Sora 영상 전 미리보기)
- 영화 포스터 톤
- 시네마틱 캠페인

**예시 프롬프트**:
```
영화적 와이드샷, 35mm 필름 룩, 따뜻한 골든 아워 조명,
한국 도심의 거리, 한 인물이 우산을 들고 걷는 모습,
앞쪽 비가 떨어지는 디테일.
```

## 자주 묻는 선택 시나리오

### Q. 마케팅 캠페인 비주얼 6종을 같은 인물로 만들고 싶다
**A**. Soul + `create_character`로 reference UUID 생성 → 6번 호출에서 동일 UUID 사용

### Q. 카드뉴스 10장에 글자가 정확히 들어가야 한다
**A**. Nano Banana + `quality=1080p` + 각 장마다 다른 시드

### Q. 이커머스 제품샷 50장 (다양한 각도)
**A**. Flux + 흰 배경 + `batch_size=4`로 후보 4종 받고 선택

### Q. 영상 썸네일 (Sora·Veo 영상에 앞서)
**A**. Cinema Studio (영상과 톤 일관)

### Q. 추상 일러스트 (아트워크)
**A**. Seedream + 대담한 색·구성 프롬프트

## 프롬프트 패턴 — 모델별 차이

### Soul 권장 패턴

```
[인물 묘사] [동작] [배경] [조명] [그레이딩] [비율]
```

### Nano Banana 권장 패턴

```
[목적: SNS 카드뉴스 1장] [비율] [헤드라인: "..."]
[배경 색] [폰트 톤] [한국어 가독성]
```

### Flux 권장 패턴

```
[제품·풍경 묘사] [배경] [조명 방향·강도]
[재질·디테일 강조] [비율] [용도]
```

### Seedream 권장 패턴

```
[스타일: 추상·일러스트·아트] [주제]
[색감 대담·실험] [분위기·감정]
```

### Cinema Studio 권장 패턴

```
[샷 종류: 와이드·미디엄·클로즈업] [필름 룩: 35mm·16mm·디지털]
[조명: 골든 아워·블루 아워·하드 라이트]
[그레이딩: 따뜻함·차가움·중간]
[주제·배경]
```

## 활용 체인

| 흐름 | 단계 |
|---|---|
| 카드뉴스 시리즈 | `card-news` → `gemini-3-image-prompt` (프롬프트) → `higgsfield-image` (Nano Banana) |
| 광고 비주얼 | `campaign-planner` → `higgsfield-image` (Cinema Studio) → `higgsfield-video` (Veo) |

| 이커머스 상세 | `commerce-product-image-pipeline` → `higgsfield-image` (Flux 다수) |
