# 카드뉴스 프롬프트 템플릿 — 10가지 구조 + 통합 프롬프트

이 자료는 한국형 카드뉴스 프롬프트 가이드(© 2026 COMMME, Built with Claude Code)를 기반으로 정리됐습니다. `[대괄호]`와 `{중괄호}` 부분만 채우면 바로 사용할 수 있는 프롬프트 모음입니다.

## 10가지 구조 유형 선택

| # | 유형 | 적합 주제 | 4장 구성 |
|---|---|---|---|
| 1 | 비교형 | 옵션 2개 비교 | 표지 · A 설명 · B 설명 · 비교표·결론 |
| 2 | 단계형 | 절차·튜토리얼 | 표지 · 1-3단계 · 4-6단계 · 요약·팁 |
| 3 | 체크리스트형 | 점검·필수 항목 | 표지 · 1-5 · 6-10 · 요약 |
| 4 | Q&A형 | 자주 묻는 질문 | 표지 · Q1-2 · Q3-4 · 핵심 결론 |
| 5 | 실수/주의사항형 | 흔한 실수·경고 | 표지 · 실수 1-3 · 실수 4-6 · 올바른 방법 |
| 6 | 입문 가이드형 | 초보자 첫 입문 | 표지 · 무엇인지 · 왜·어디 쓰는지 · 시작하는 법 |
| 7 | 용어 정리형 | 핵심 용어 모음 | 표지 · 용어 1-3 · 용어 4-6 · 용어 관계도 |
| 8 | 문제-해결형 | 페인포인트 해결 | 표지·공감 · 원인 · 해결책 · 실전 팁 |
| 9 | 예시 중심형 | 실전 예시 강조 | 표지 · 기본 개념 · 실제 예시 1-2 · 따라할 예시 |
| 10 | 템플릿 제공형 | 복붙 템플릿 | 표지 · 템플릿 1 · 템플릿 2 · 사용 팁 |

## 구조별 프롬프트 (복붙 가능)

### ① 비교형

```
[주제 A]와 [주제 B]를 비교하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [주제 A vs 주제 B], 한 줄 요약
2장: [주제 A] 설명 — 특징, 장점, 추천 상황
3장: [주제 B] 설명 — 특징, 장점, 추천 상황
4장: 비교 정리 — 차이점 표, 한 줄 결론, 어떤 사람에게 맞는지

초보자도 이해하기 쉽게, 표와 아이콘을 활용해서.
```

### ② 단계형

```
[주제]를 단계별로 설명하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], 한 줄 요약
2장: 1단계~3단계 설명
3장: 4단계~6단계 설명
4장: 전체 요약 + 실전 팁 + 주의사항

숫자, 화살표, 흐름형 박스를 활용해서 단계가 한눈에 보이게.
예: 하네스 만드는 법
```

### ③ 체크리스트형

```
[주제] 체크리스트 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "이것만 체크하면 됩니다" 느낌
2장: 체크리스트 1~5
3장: 체크리스트 6~10
4장: 핵심 체크포인트 요약 + 마지막 한 줄 정리

체크박스·아이콘·간단한 설명. 저장하고 싶은 카드뉴스 느낌으로.
예: Claude Code 시작 전 체크리스트
```

### ④ Q&A형

```
[주제]에 대한 자주 묻는 질문을 정리한 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "헷갈리는 질문 모음" 느낌
2장: 질문 1~2개와 답변
3장: 질문 3~4개와 답변
4장: 핵심 요약 + 가장 중요한 한 줄 결론

질문은 굵게, 답변은 짧고 쉽게.
예: Claude Code 초보자 Q&A
```

### ⑤ 실수/주의사항형

```
[주제]를 할 때 많이 하는 실수와 주의사항을 정리한 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "이 실수는 피하세요" 느낌
2장: 자주 하는 실수 1~3
3장: 자주 하는 실수 4~6
4장: 올바른 방법 요약 + 한 줄 팁

경고 아이콘·체크 아이콘. 직관적으로 정리.
예: 하네스 만들 때 흔한 실수
```

### ⑥ 입문 가이드형

```
완전 초보자를 위한 [주제] 입문 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "처음이라면 이것부터"
2장: 이 주제가 무엇인지 쉽게 설명
3장: 왜 중요한지 + 어디에 쓰는지
4장: 시작하는 방법 + 추천 첫 행동

전문 용어 최소화. 초등학생도 이해할 수 있을 만큼 쉽게.
예: Claude Code 입문 가이드
```

### ⑦ 용어 정리형

```
[주제]와 관련된 핵심 용어를 정리하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "핵심 용어 한 번에 정리"
2장: 용어 1~3 설명
3장: 용어 4~6 설명
4장: 용어 간 관계 정리 + 한 줄 요약

각 용어는 "쉽게 말하면" 형식으로.
예: Claude Chat / Code / CLI / 하네스 용어 정리
```

### ⑧ 문제-해결형

```
[문제 상황]을 해결하는 방법을 설명하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [문제 상황], 한 줄 공감 문구
2장: 왜 이런 문제가 생기는지 설명
3장: 해결 방법 3~5가지
4장: 바로 써먹는 실전 팁 + 요약

문제 → 원인 → 해결 순서가 분명하게.
예: Claude Code 개념이 너무 헷갈릴 때
```

### ⑨ 예시 중심형

```
[주제]를 실제 예시와 함께 설명하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "예시로 이해하는"
2장: 기본 개념 설명
3장: 실제 예시 1~2개
4장: 따라 해볼 수 있는 예시 프롬프트 + 요약

개념만 말하지 말고, 실전에서 어떻게 쓰는지 예시 필수.
예: 하네스 제작 요청 프롬프트 예시
```

### ⑩ 템플릿 제공형

```
[주제]를 바로 따라할 수 있는 템플릿형 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목], "복붙해서 바로 쓰는 템플릿"
2장: 템플릿 1개 제시
3장: 템플릿 2개 제시
4장: 사용 팁 + 바꿔 넣으면 좋은 항목 정리

실제로 복사해서 쓸 수 있는 문장 형태로.
예: Claude에게 하네스 요청하는 프롬프트 템플릿
```

## 공통 스타일 문구 — 모든 프롬프트 맨 뒤에 붙이기

### 표준 톤 (한국형 MZ)

```
스타일:
- 레이아웃/장: 인스타/스레드용 1:1 비율, 4장 카드뉴스
- 컬러: 크림/아이보리 배경 + 오렌지 포인트 컬러
- 텍스트스타일: 굵고 가독성 좋은 한글 타이포그래피
- 톤앤매너: 둥근 박스, 정돈된 여백, 깔끔한 인포그래픽 스타일
- 세련되고 따뜻한 MZ 감성
- 페이지 번호 표시
- 전체 카드의 외곽선과 박스 테두리 굵기 일관
```

### Claude 톤 변형 (Anthropic Orange 기반)

```
스타일:
- 레이아웃/장: 인스타용 1:1 비율, 4장 카드뉴스
- 컬러: Light Beige #faf9f5 배경 + Anthropic Orange #d97757 포인트
- 보조 색: Anthropic Blue #6a9bcc 강조
- 텍스트: Pretendard Bold 헤딩 + Regular 본문, Dark #141413
- 톤앤매너: 둥근 박스 (border-radius 12-16px), 시원한 여백
- 세련되고 신뢰감 있는 톤
- 페이지 번호 우측 하단 작은 글씨
- 외곽선·박스 테두리 1.5pt 일관
```

### 추가 톤 변형 (실전 경험)

```
[브랜드 비즈니스]
- 컬러: 화이트 배경 + 진한 네이비 포인트
- 톤: 격식 있고 신뢰감 있는

[발랄·캐주얼]
- 컬러: 파스텔 핑크 + 옐로 포인트
- 톤: 친근하고 활기찬

[다크 톤]
- 컬러: 차콜 #1a1a1a 배경 + 네온 오렌지 포인트
- 톤: 모던하고 하이엔드
```

## 최종 범용 프롬프트 (구조 + 디자인 통합)

```
[주제]를 설명하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지
- 제목: [제목]
- 부제: [부제]
- 한 줄 핵심: [한 줄 요약]
- 전체 내용을 상징하는 구조도 또는 대표 비주얼

2장: {구조 유형 선택: 단계형 / 비교형 / 체크리스트형 / Q&A형}
- 제목: [2장 제목]
- 핵심 내용을 번호형 또는 흐름형으로 정리

3장: {구조 유형 동일}
- 제목: [3장 제목]
- 핵심 내용 확장 또는 예시

4장: 요약·CTA
- 한 줄 요약
- 저장·공유·팔로우 중 1개 액션

스타일:
- 레이아웃: 인스타용 1:1, 4장
- 컬러: [크림 배경 + 오렌지 포인트] 또는 [Claude 톤]
- 텍스트: 굵고 가독성 좋은 한글 타이포
- 톤: 둥근 박스, 정돈된 여백, 인포그래픽 스타일
- 페이지 번호 표시
- 외곽선·박스 테두리 일관
```

## 꿀팁 — 프롬프트 뒤에 붙이는 문장

1-3개 골라서 프롬프트 맨 뒤에 추가하면 결과 품질이 올라갑니다.

```
- 텍스트는 실제 카드뉴스처럼 정확하게 렌더링해줘
- 전체 카드의 테두리 굵기를 일관되게 맞춰줘
- 정보량은 많아도 복잡해 보이지 않게 정리해줘
- 저장하고 싶은 느낌의 SNS 카드뉴스처럼 만들어줘
- 장마다 레이아웃은 달라도 시리즈 전체 톤앤매너는 통일해줘
- 마스코트를 활용해서 기획해줘
- 한국어 가독성 우선 — 한 문장 한 줄 이내
- 색 대비 4.5:1 이상 (WCAG AA)
- AI가 만든 듯한 진부 표현 회피 (혁신적인·차세대 등)
```

## 사용 흐름

```
1. 주제 정하기 (예: "AI 글쓰기 도구 추천")
2. 10가지 구조 유형 중 1개 선택 (예: 비교형 또는 체크리스트형)
3. 위 프롬프트 복사·붙여넣기 → [대괄호] 부분 채우기
4. 공통 스타일 문구 끝에 추가
5. 꿀팁 1-3개 골라 추가
6. Nano Banana Pro·Midjourney·DALL-E 등 이미지 도구에 입력
7. 결과 검수 (사실 확인·AI 슬롭 회피)
```
