# 카드뉴스 (Card News)

## 개요

인스타그램·스레드용 4장 카드뉴스를 기획·작성합니다. **10가지 구조 유형 자동 선택**과 통합 프롬프트, Claude 톤 변형 디자인 시스템을 제공합니다. 이미지 생성은 `moai-media`의 `gemini-3-image-prompt` 또는 `nano-banana`에 위임합니다.

배경 자료: [카드뉴스 프롬프트 완전 가이드 (© 2026 COMMME)](https://canyon-newsboy-274.notion.site/36495b7e6610817da8c0f911932c4d9f) 한국형 카드뉴스 프롬프트 자료.

## 트리거 키워드

카드뉴스, 캐러셀, 인스타그램 카드, 스레드 카드, 슬라이드, AI 이미지 카드, 인포그래픽 카드, SNS 카드, 4장 카드

## 10가지 구조 유형

사용자 주제에 맞춰 다음 10가지 중 자동 선택 (또는 AskUserQuestion으로 확정):

| # | 유형 | 적합 주제 | 키워드 매칭 |
|---|---|---|---|
| 1 | **비교형** | 옵션 2개 비교 | "A vs B", "차이", "어떤 게 좋은가" |
| 2 | **단계형** | 절차·튜토리얼 | "방법", "순서", "단계", "어떻게" |
| 3 | **체크리스트형** | 점검 항목·필수 | "체크리스트", "준비물", "필수" |
| 4 | **Q&A형** | 자주 묻는 질문 | "FAQ", "궁금증", "헷갈리는" |
| 5 | **실수/주의사항형** | 흔한 실수·경고 | "실수", "피할 점", "주의" |
| 6 | **입문 가이드형** | 초보자 첫 입문 | "처음", "입문", "초보자", "시작" |
| 7 | **용어 정리형** | 핵심 용어 모음 | "용어", "개념 정리", "뜻" |
| 8 | **문제-해결형** | 페인포인트 해결 | "[문제] 어떻게", "해결", "막힐 때" |
| 9 | **예시 중심형** | 실전 예시 강조 | "예시", "실전", "케이스" |
| 10 | **템플릿 제공형** | 복붙 템플릿 | "템플릿", "복붙", "양식" |

상세 프롬프트는 [`references/prompt-templates.md`](./references/prompt-templates.md)에 정리됐습니다.

## 워크플로우

### 1단계 — 주제·목적 파악

사용자 한 줄 입력에서 다음을 추출:
- 주제 (예: "Claude Code 시작 가이드")
- 목적: 정보 전달·브랜드 인지·제품 소개·리드 수집
- 타겟 (직장인·창업자·개발자·일반 대중)

### 2단계 — 구조 유형 자동 선택 또는 확인

키워드 매칭으로 자동 선택 후 사용자에게 확인. 매칭이 모호하면 AskUserQuestion으로 4-6개 후보 제시.

### 3단계 — 4장 구성 설계

선택된 유형의 표준 4장 골격에 사용자 내용을 채움. 각 장은 한 메시지·15-30자 카피·시각 요소 1개.

### 4단계 — 통합 프롬프트 생성

`references/prompt-templates.md`의 통합 프롬프트 + 공통 스타일 문구 + 꿀팁 1-3개를 합쳐 **이미지 도구에 그대로 붙여 넣을 수 있는 완성 프롬프트** 출력.

### 5단계 — 디자인 톤 선택

| 톤 | 컬러 | 적합 |
|---|---|---|
| **한국형 MZ (기본)** | 크림/아이보리 + 오렌지 포인트 | 일반·라이프스타일·교육 |
| **Claude 톤** | Light Beige `#faf9f5` + Anthropic Orange `#d97757` + Pretendard | 테크·B2B·신뢰감 |
| **브랜드 비즈니스** | 화이트 + 진한 네이비 | 격식·금융·법무 |
| **발랄·캐주얼** | 파스텔 핑크 + 옐로 | 친근·아동·뷰티 |
| **다크 톤** | 차콜 #1a1a1a + 네온 오렌지 | 모던·하이엔드 |

### 6단계 — AI 이미지 생성 위임

`moai-media:gemini-3-image-prompt` 또는 `nano-banana`에 프롬프트 전달. 모델·해상도·비율 미지정 시 사용자 확인:

| 옵션 | 권장 |
|---|---|
| 모델 | Nano Banana Pro (2K 텍스트 SOTA) · Gemini 3 Pro Image |
| 해상도 | 1K (웹) · 2K (인쇄·고품질) |
| 비율 | 1:1 (인스타 권장) · 9:16 (스토리) · 3:4 (피드) |

### 7단계 — 검수 + 산출물

- AI 슬롭 카피 검수 (`moai-core:ai-slop-reviewer`)
- 한국어 자연화 (`moai-content:humanize-korean`)
- 사실 확인 (통계·수치·인물)
- 산출물: 카드 4장 텍스트 + 디자인 가이드 + 이미지 프롬프트 + 인스타 캡션·해시태그

## 실전 카드뉴스 패턴

### 1초 시선 고정 첫 카드 4유형

| 유형 | 첫 카드 카피 예시 | 적용 구조 |
|---|---|---|
| 질문형 | "혹시 이런 경험 있나요?" | 문제-해결형 |
| 통계 충격형 | "한국인 78%가 모르는 ~" | 비교형·정보 |
| 약속형 | "5분 후, OO를 알게 됩니다" | 입문·단계형 |
| 시각 임팩트 | 색·이미지로 시선 잡기 | 모든 유형 |

### 콘텐츠 흐름 (긴장 → 완화 → 임팩트)

```
1장: 긴장 — 문제·페인·질문 제시
2-3장: 완화 — 설명·분석·해결책
4장: 임팩트 — "와!" 모먼트 + CTA
```

### 한 카드 한 메시지

- 한 카드 = 한 헤드라인 + 한 단락 (15-30자)
- 이미지 + 텍스트 분리 (둘 다 강조 시 충돌)
- 글자 크기 ≥ 24pt (모바일 가독)
- 여백 30%+ (꽉 차면 못 읽음)

### 한국어 가독성

| 항목 | 권장 |
|---|---|
| 문장 길이 | 한 줄 24자 이내 |
| 단어 | 한자어 ↓ 우리말 ↑ |
| 줄간격 | 1.5배 이상 |
| 색 대비 | WCAG AA 4.5:1 |
| 폰트 | Pretendard·Noto Sans KR |
| 강조 | Bold > 색 > 크기 순 |

### 마지막 카드 CTA 6유형 (1개만 선택)

| CTA | 적용 | 효과 |
|---|---|---|
| 저장 | 정보형 (체크리스트·용어) | 알고리즘 ↑ |
| 공유 | 친구 추천형 (실수·꿀팁) | 도달 ↑ |
| 팔로우 | 시리즈 후속 약속 | 구독 ↑ |
| 링크 | 외부 전환 (제품·블로그) | 클릭 ↑ |
| 댓글 | 토론·참여형 | 참여 ↑ |
| DM | 1:1 상담·문의 | 리드 ↑ |

## 통합 프롬프트 — 즉시 사용

```
[주제]를 설명하는 카드뉴스 4장을 만들어줘.

구성:
1장: 표지 — [제목] · [부제] · 한 줄 핵심
2장: {구조 유형 선택: 비교/단계/체크리스트/Q&A 중}
3장: 본문 확장 또는 예시
4장: 요약 + CTA ({저장/공유/팔로우/링크/댓글/DM 중 1개})

스타일:
- 인스타용 1:1, 4장
- [컬러 톤 선택]
- 굵고 가독성 좋은 한글 타이포
- 둥근 박스, 시원한 여백, 인포그래픽 스타일
- 페이지 번호 표시
- 외곽선·박스 테두리 굵기 일관

꿀팁:
- 텍스트는 실제 카드뉴스처럼 정확하게 렌더링
- 정보량 많아도 복잡해 보이지 않게
- 시리즈 전체 톤앤매너 통일
```

상세는 [`references/prompt-templates.md`](./references/prompt-templates.md).

## 사용 예시

- "Claude Code 입문 카드뉴스" → 입문 가이드형 + Claude 톤
- "AI 글쓰기 도구 5개 비교" → 비교형 + 한국형 MZ
- "스타트업 투자 유치 단계" → 단계형 + 브랜드 비즈니스
- "프롬프트 엔지니어링 자주 묻는 질문" → Q&A형 + Claude 톤
- "마케팅 자동화 흔한 실수" → 실수형 + 한국형 MZ
- "개발자 면접 체크리스트" → 체크리스트형 + 다크 톤

## 출력 형식

- **카드별 텍스트**: 15-30자, 장당 핵심 메시지
- **디자인 가이드**: 레이아웃·폰트·컬러·여백·구조 유형
- **AI 이미지 프롬프트**: 통합 프롬프트 (Gemini 3·Midjourney·DALL-E 호환)
- **인스타 캡션**: 본문 1-3 문단 + 해시태그 5-10개

## 이미지 생성 연동

이미지 생성은 **`moai-media`**가 담당. card-news는 프롬프트만 생성:

| 모델 | 강점 | 권장 |
|---|---|---|
| Nano Banana Pro (gemini-3-pro-image-preview) | 2K, 텍스트 SOTA | 카드뉴스 권장 ★ |
| Nano Banana 2 (gemini-3.1-flash-image-preview) | 1K, 빠름, 저비용 | 미리보기·반복 시도 |
| Midjourney v8.1 | 비주얼 일러스트 강함 | 일러스트 중심 |
| DALL-E 3 | 텍스트 안에 들어가는 정확성 | 텍스트가 핵심일 때 |

Gemini API 키 설정은 `moai-media` 가이드 참고. 키 없으면 프롬프트만 제공하고 외부 도구에서 직접 생성.

## 주의사항

### AI 생성 콘텐츠 검수

- AI가 만든 통계·수치·인물 정보는 **반드시 원출처 확인** 후 게시
- AI 슬롭 표현 (혁신적인·차세대·재정의하는) 회피 → `moai-content:humanize-korean` 체이닝 권장
- 카드 1장 30자 초과 시 핵심 키워드만 남기기

### 플랫폼 규격

- 인스타 캐러셀: 1:1 (1080×1080) 권장, 최대 10장
- 인스타 스토리: 9:16 (1080×1920)
- 카카오 채널·스레드: 1:1 또는 4:5
- 최신 규격은 플랫폼 공식 채널 확인

### 폰트 라이선스

- Pretendard·Noto Sans KR 오픈소스 (상업·배포 자유)
- 굴림·맑은 고딕 (Windows 환경 한정)
- 외부 폰트 사용 시 라이선스 확인

### 시리즈 일관성

- 시리즈로 운영할 때 톤앤매너 통일 — 색·폰트·박스 모양 동일
- 페이지 번호는 모든 카드에 (위치·크기 통일)
- 마스코트 사용 시 모든 카드에 일관
