# 퍼포먼스 리포트 (Performance Report)

## 개요

GA4, 네이버 광고, 메타(Meta) 광고, 카카오모먼트, 구글 광고 등 한국 시장 주요 채널의 성과 데이터를 통합 분석하여 마케팅 성과 보고서를 생성합니다.

데이터 해석과 인사이트 도출, 다음 액션 플랜까지 포함한 완성형 리포트를 제공합니다.

## 트리거 키워드

성과 보고서, KPI 리포트, ROAS 분석, 광고 성과, GA4 분석, 메타 광고 리포트, 네이버 광고 분석, 퍼포먼스 리포트, 마케팅 ROI, 전환율 분석, CTR, CPC, 광고비 분석

## 실전 그로스 마케팅 리포트 패턴 (한국 시장)

리포트는 단순 데이터 나열이 아닙니다. **고객 행동 변화의 가설·실험·검증 → 다음 액션**으로 이어져야 진짜 성과 리포트입니다.

### 7개 핵심 패턴

**① 그로스 마케팅 3대 요소**

- **데이터**: 고객 행동을 정량화·측정
- **고객 가설**: "고객 행동 B를 이끌어 내려면 행동 A가 필요"
- **실험**: 가설 검증으로 행동 변화 입증

리포트 = 위 3요소의 결과 + 다음 액션. **데이터만 있고 가설 없으면** 의미 없음.

**② "측정 → 관리 → 개선" 사이클 (피터 드러커)**

> "측정할 수 없으면 관리할 수 없고, 관리할 수 없으면 개선할 수 없다."

- 측정 없으면 관리 불가
- 관리 없으면 개선 불가
- 모든 마케팅 액션은 메트릭 가능해야 — 어렵더라도 정량화 우선

**③ 한국 D2C·이커머스 메트릭 표준식**

```
유저 유입 × CTR × CVR × AOV = 매출
매출 − 원가 − 배송비 − 광고비 = 이익
이익 × 재구매율 = 누적 이익
```

ROAS 단일 지표만 보지 말고 **누적 이익 = LTV × 재구매**까지 봐야 진짜 그로스. 일반적인 한국 D2C/커머스 매출 발생 과정:
- 유저 유입 → CTR(클릭률) → CVR(전환율) → AOV(평균 주문 단가)

**④ 고객 가치 분석으로 채널·세그먼트 우선순위 결정 (펫프렌즈 케이스)**

| 비교 | 앱 | 웹 |
|---|---|---|
| 180일 LTV | 4배 | 1배 |
| CAC | 높음 | 낮음 |
| ROI | **앱 우세** | 웹 우세 (착시) |
| 1년 후 누적 매출 | 15배 | 1배 |

**CAC 낮은 채널 ≠ 좋은 채널**. 180일 LTV ÷ CAC가 진짜 ROI. 서울 고양이 앱 고객 vs 지방 강아지 웹 고객 — 1년 후 15배 차이날 수 있음.

**⑤ 한국 채널별 진단 체크리스트**

| 채널 | 핵심 지표 | 함정 |
|---|---|---|
| **네이버 광고** | 파워링크 vs 쇼핑 광고 ROAS, C-Rank 영향, 스마트플레이스 | 키워드 단가 변동성 큼 |
| **메타 (인스타·페북)** | 릴스 vs 피드 광고, 학습 기간 48~72시간, 광고 소재 A/B | **학습 기간 절대 미수정** |
| **구글** | 품질점수, GA4 연동, 스마트 vs 수동 캠페인 | 스마트 캠페인은 데이터 적을 때만 |
| **카카오** | 채널 알림·디스플레이·쇼핑 광고 | 슈퍼 타겟 90% 열람 = CRM 채널 |
| **유튜브 (쇼츠 + 일반)** | CPV·CTR·시청 완료율 | 쇼츠는 6초·15초 후킹 절대적 |

**⑥ MVT (Minimum Viable Test) — 완벽한 실험 X**

| 마인드 | 변화 |
|---|---|
| ❌ 한 번 실험으로 완벽한 결과 찾기 | ✅ 연속·일관된 여러 실험으로 답 |
| ❌ 통제 변수 100% 통제 | ✅ 최소 충족 요건 수준 검증 |
| ❌ 통계 유의미만 해석 | ✅ 작은 실마리도 활용 |

회사 환경 = 실험실 아님. **합리적 해결의 실마리**가 1차 목표.

**⑦ 한국 광고 환경 3대 어려움 (2024~2026)**

- **시장 변화**: 광고 생태계 복잡도 폭증 (2015→2019→2024 정리 자료조차 못 찾을 정도)
- **기술 변화**: iOS ATT (2021.04) + 구글 쿠키 종료 → 1st party 데이터 의무
- **예산 압박**: CAC 5년 50% 상승 → 효율 우선 (Profitwell 데이터)

대응 전략:
- **선택과 집중**: "합리적으로 돈 써가며" — 효율 극대화
- **죽일 건 죽이고, 키울 건 키우는 최적화** 
- 1st party 데이터 (이메일·전화·구매 이력) 자산화 우선

### 그로스 실험 변수 표준 (필수 문서화)

| 변수 | 정의 | 예시 |
|---|---|---|
| **독립 변수** | 우리가 조작하는 것 (A) | 새 광고 소재 도입 |
| **종속 변수** | 측정하는 결과 (B) | CTR·CVR·매출 |
| **통제 변수** | 동일 유지 | 타깃·예산·기간 |

실험 그룹 (통제 + 독립) vs 통제 그룹 (통제만)의 종속 변수 차이 = 독립 변수의 영향.

### 한국 리포트 표준 포맷 (5분 안에 읽힘)

```markdown
# [기간] 마케팅 성과 리포트

## 경영진 요약 (3줄)
- 총 광고비 / 총 매출 / 전체 ROAS
- 전기 대비 핵심 변화
- 다음 분기 우선순위 1줄

## 채널별 성과
| 채널 | 광고비 | 매출 | ROAS | 전월 대비 |

## 핵심 발견 3가지 (인사이트 ≠ 팩트)

## 다음 액션 플랜
- [ ] 예산 재배분: A 채널 +20% / B 채널 -30%
- [ ] 신규 실험: ...
- [ ] 중단: ...
```

### 안티 패턴

- 데이터 나열만 (시사점 없음)
- ROAS만 보고 LTV·CAC 무시
- 채널 간 비교 없이 단일 채널만
- "전월 대비 +5%" 같은 무의미한 비교 (계절성·캠페인 차이 미고려)
- 실험 가설 없이 사후 해석만

> 💡 한국 그로스 리포트의 진짜 가치: **데이터 → 가설 → 다음 액션** 사슬이 명확해야 합니다. ROAS만 보고하는 리포트는 의사결정에 도움 안 됩니다.

## 워크플로우

### 1단계: 보고서 범위 설정

보고 기간 선택(주간/월간/분기/연간), 포함할 채널 선택(유료 광고, 유기적 채널, 분석 도구), 목표 KPI 확인을 수행합니다.

### 2단계: 핵심 지표 수집 가이드

사용자가 제공할 데이터 형식을 안내합니다:
- GA4 필수 데이터: 세션 수, 사용자 수, 전환수, 전환율, 채널별 획득 데이터, 이탈률, 세션 지속 시간
- 광고 플랫폼 데이터: ROAS, CPA, CTR, CPC, CVR, CPM

### 3단계: 채널별 분석

**네이버 광고:** 파워링크 vs 쇼핑 광고 성과 비교, 스마트플레이스 노출 현황, 네이버 쇼핑 ROAS, C-Rank 영향 유기 트래픽 변화를 분석합니다.

**메타(인스타그램/페이스북) 광고:** 2026년 알고리즘 변화 반영(릴스 vs 피드 광고 성과 비교, 딥 인게이지먼트 지표 확인), 오디언스 인사이트, 광고 소재 A/B 테스트 결과를 분석합니다.

**구글 광고:** 검색 캠페인 품질점수, 전환 추적(GA4 연동 확인), 스마트 캠페인 vs 수동 캠페인 성과를 분석합니다.

### 4단계: 보고서 생성 (표준 포맷)

경영진 요약(총 광고비, 총 매출, 전체 ROAS, 전기 대비, 핵심 인사이트), 채널별 성과표, 주요 발견 및 인사이트, 개선 기회, 다음 기간 액션 플랜을 포함한 보고서를 생성합니다.

### 5단계: 인사이트 도출 및 권고안

성과 부진 채널 원인 분석, 예산 재배분 시뮬레이션, 다음 기간 테스트 가설 제안을 수행합니다.

## 사용 예시

**예시 1**: "지난달 네이버+메타 광고 성과 통합 분석해줘. 데이터 여기 있어: [데이터]"
→ 데이터 파싱 → 채널별 KPI → 비교 분석 → 인사이트 → 다음 달 권고안

**예시 2**: "분기 마케팅 성과 경영진 보고서 만들어줘. 총 광고비 3천만원, ROAS 350%"
→ Executive Summary → 채널별 성과표 → 주요 발견 → 다음 분기 전략

## 출력 형식

- 채널 통합 성과 대시보드 (마크다운/표 형식)
- 경영진용 요약 리포트 (1페이지)
- 실무팀용 상세 분석 리포트
- 다음 기간 예산 배분 권고안
- A/B 테스트 결과 분석

## 주의사항

| 상황 | 대응 |
|------|------|
| 데이터가 없거나 불완전한 경우 | 보유한 데이터로 분석 가능한 범위 제시. 누락 데이터 수집 방법 안내 |
| 채널이 너무 많아 복잡한 경우 | 매출 기여도 상위 2~3개 채널 집중 분석 후 나머지 요약 처리 |
| 업종 벤치마크가 없는 경우 | 범용 업종 기준값 제시. 사용자 직접 측정 KPI 설정 권고 |
