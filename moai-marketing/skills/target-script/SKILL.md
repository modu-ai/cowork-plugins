# 타겟 스크립트 (Target Script)

## 개요

타겟 고객 맞춤 메시징 스크립트 생성 스킬입니다. 타겟 오디언스 분석, 페인포인트 도출, 핵심 메시지 생성, 채널별 변환, A/B 테스트 제안의 5단계 파이프라인을 통해 타겟 고객에게 최적화된 메시징 스크립트를 생성합니다.

단순한 카피라이팅을 넘어, 타겟 오디언스의 심리적 특성과 페인포인트를 분석하여 설득력 있는 메시징 전략을 수립합니다.

## 실전 카피라이팅·메시징 패턴 (한국 시장)

35년 카피라이터 정철·와디즈 광고 PD·한국 메시징 노하우에서 추출한 실전 패턴입니다. AIDA·PAS 모델 위에 한국 특화 카피 작법을 얹어 진짜 설득력 있는 메시지를 만듭니다.

### 7개 핵심 패턴

**① 구체성 = 카피 제1원칙 (그림이 그려져야)**

| 추상 | 구체 |
|---|---|
| 잘생겼다 | 강동원 동생일 거야 |
| 많다 | 삼십육만 칠천팔백 개 |
| 꼼꼼하다 | 손톱 10개 깎는 데 꼬박 20분 |

**구체적인 카피 = 머릿속에 그림이 그려짐.** 그림이 그려진다 = 사진 한 장이 함께 메시지에 첨부되는 효과. "추운 날, 국수 따끈하게 말아 놓겠습니다"(청첩장) vs "자리를 빛내 주십시오"(주례사) — 차이는 구체성.

**② 낯설게·불편하게 조합하기**

- 익숙한 조합 ("아름다운 꿈") → 졸음·하품·취침
- 낯선 조합 ("아름다운 바퀴벌레") → 멈춤·반응

**카피의 힘 = 낯선 조합에서 나옴**. 세상 모든 단어를 한 줄로 세웠을 때 오른쪽 끝과 왼쪽 끝, 평생 만날 일 없을 단어를 핀셋으로 뽑아 조합. "휴대용 선생님"(PMP) / "휴대용 영화관" 같은 조합.

**③ 사칙연산 카피 (정철식)**

| 연산 | 사용법 | 한국 사례 |
|---|---|---|
| **곱하기** | 한 문장에 같은 단어 2회 반복 | "공부보다 중요한 것을 공부합니다" / "밥보다 더 맛있는 밥" (햇반) / "당신의 생각을 생각합니다" (일룸) |
| **나누기** | 긴 헤드라인을 헤드+서브로 분리 | "밥입니다 / 든든한 한 끼, 삼양 쌀라면" |
| **더하기** | 외부 단어로 맛 추가 | 기본 의미 + 감정·관계 |
| **빼기** | 군더더기 제거 | "지하철에서도 동영상 강의를 들을 수 있는 물건" → "휴대용 선생님" |

**④ "카피는 make가 아니라 search"**

어깨에 힘 들어가면 폭투. 없는 것을 만들어내는 게 아니라 **우리가 늘 쓰는 말 중 딱 맞는 것을 찾기**. 김치톡톡 사례:
- ❌ make: "반찬의 황제, 김치! / 김치의 궁전, 톡톡!" (억지)
- ✅ search: 자연스러운 표현 찾기

**손이 아니라 눈으로 쓰는 것**. 두리번두리번 살피다가 "이거다!" 하는 것을 발견.

**⑤ 한자어·전문어 → 일상어 전환 (5학년 3반 혜진이 기준)**

| 어려운 표현 | 쉬운 표현 |
|---|---|
| 광역 자치단체장 선거 투표 | 도지사 뽑는 날 |
| 예방 접종 권고 | 주사 맞으세요 |
| 운영진 미숙으로 인한 혼란 | 일 못해서 헷갈리게 했습니다 |
| 담배꽁초나 가래침을 바닥에 뱉지 마세요 | + "청소하시는 아주머니 관절이 너무 힘들어요" (울림 추가) |

한자어 → 북경반점으로 돌려보내고 한국 토박이말 사용. "5학년 3반 혜진이가 이해할 만한 표현"이 베스트.

**⑥ 와디즈식 광고 소재 4단 (한국 크라우드펀딩 검증)**

1. **후크**: 첫 3초 시각·청각 자극 (전문가 동물·놀라운 비교·도발적 질문)
2. **공감 페인**: "당신도 이런 경험 있죠?" (구체적 상황 묘사)
3. **솔루션**: 우리 제품 = 그 페인의 해답 (Before/After)
4. **신뢰·CTA**: 후기·수치·한정성 ("이미 1,238명이 구매") + 클릭

**⑦ 채널별 카피 톤 매트릭스**

| 채널 | 길이 | 톤 | 특화 |
|---|---|---|---|
| 이메일 제목 | 10자 이내 | 호기심·이름 개인화 | 첫 단어 임팩트 |
| 인스타 캡션 | 150자 핵심 + CTA | 친근·이모지 | 첫 줄에 후킹 |
| 페북 광고 | 90자 + 본문 | 후킹 + 구체성 | 영상 자막 매칭 |
| 검색 광고 | 25+90자 | 키워드 정확 매칭 | 의도 부합 |
| 랜딩 헤드라인 | 25자 이내 | "그림이 그려지는" | 광고 헤드라인과 일치 |
| 카카오톡 채널 | 70자 + 이미지 | 친구처럼 | 이모티콘 |
| X (트위터) | 140자 | 인사이트·밈 | 줄임말·해시태그 |

### AIDA / PAS / 4P 카피 공식 (한국 검증)

| 공식 | 4단 |
|---|---|
| **AIDA** | Attention → Interest → Desire → Action |
| **PAS** | Problem → Agitate → Solution |
| **4P** | Picture → Promise → Prove → Push |

**B2C·이커머스**: PAS 가장 강력 (페인 → 자극 → 해결)
**B2B·SaaS**: AIDA 표준 (관심 → 학습 → 욕구 → 도입)
**광고 영상**: 4P 추천 (시각화 → 약속 → 증명 → 결정)

### 한국 카피 안티 패턴

- 영문 직역 ("Just Do It"식 강함이 한국에선 어색)
- 추상적 형용사 나열 ("최고의" "프리미엄" "혁신적")
- 자랑 위주 ("우리 회사는 OO 보유" — 고객 관심 X)
- 어려운 한자어·전문어 ("전사적 자원 관리" → "회사 운영 시스템")
- CTA 없음 (다음 행동 불명확)

> 💡 한국 카피의 진짜 차별점: **그림이 그려지는 구체성 + 낯선 조합의 불편함 + 5학년 3반 혜진이도 이해할 수 있는 쉬운 표현**. 이 셋이 모이면 광고 효율이 2~5배 차이가 납니다.

## 워크플로우

### 단계 1: 타겟 분석 (Target Audience Analysis)

타겟 고객의 인구통계학적 특성, 심리적 특성, 행동 패턴을 분석하여 명확한 Buyer Persona를 구축합니다. 타겟 고객이 가진 문제(Pain Point)와 욕구(Desire)를 식별합니다.

**출력 항목:** Buyer Persona 프로파일, 심리적 특성, 구매 여정 단계(인지 → 고려 → 구매 → 유지 → 확산), 페인포인트 식별, 욕구 식별

### 단계 2: 페인포인트 도출 (Pain Point Extraction)

타겟 고객이 겪고 있는 구체적인 페인포인트를 3-5개 식별하고, 각 페인포인트의 심각성과 긴급성을 평가합니다. 페인포인트를 해결하는 것이 타겟 고객에게 가져다줄 가치(Value)를 명확히 합니다.

**출력 항목:** 핵심 페인포인트 3-5개, 페인포인트 심각성 평가, 페인포인트 해결 시 가치, 페인포인트별 메시지 후크

### 단계 3: 핵심 메시지 생성 (Core Message Generation)

페인포인트와 가치 제안을 바탕으로 핵심 메시지를 생성합니다. AIDA 모델(Attention-Interest-Desire-Action)과 PAS 모델(Problem-Agitate-Solution)을 활용하여 설득력 있는 메시지 구조를 설계합니다.

**출력 항목:** 핵심 가치 제안, AIDA 모델 메시지, PAS 모델 메시지, 메시지 톤앤매너

### 단계 4: 채널별 변환 (Channel-Specific Adaptation)

핵심 메시지를 각 채널(이메일, SNS, 웹, 광고)의 특성에 맞게 변환합니다. 각 채널의 길이 제한, 형식, 사용자 행동 패턴을 고려하여 최적화된 스크립트를 생성합니다.

**출력 항목:** 이메일 스크립트(콜드 이메일, 뉴스레터, 트랜잭션 이메일), SNS 스크립트(Instagram, LinkedIn, Twitter/X, TikTok), 웹 스크립트(랜딩 페이지, 제품 상세페이지, 블로그 포스트), 광고 스크립트(검색 광고, 디스플레이 광고, 동영상 광고)

### 단계 5: A/B 테스트 제안 (A/B Testing Proposal)

각 채널별로 2-3개의 변형(Variant)을 제안하고, A/B 테스트를 통해 최적의 메시지를 찾을 수 있는 실험 계획을 수립합니다.

**출력 항목:** A/B 테스트 변형(헤드라인, CTA 버튼, 메시지 톤, 길이), 테스트 가설, 성공 지표(CTR, 전환율, 오픈률, 참여율), 실험 기간

## 사용 예시

**예시 1**: B2B SaaS 제품 타겟 스크립트
- 타겟 고객: 중소 제조업체 경영진 (CEO, 생산관리자, 연 매출 10-100억원)
- 제품: AI 기반 생산 최적화 SaaS (생산 비용 15% 절감)
- 캠페인 목표: 무료 체험 신청 유도 (30일 무료 체험)
- 채널: 이메일, LinkedIn, 랜딩 페이지

**예시 2**: D2C 브랜드 타겟 스크립트
- 타겟 고객: 반려동물 보유 1인 가구, 연 소득 5천만원 이상, 2030 여성
- 제품: 프리미엄 반려동물 유기농 사료 (100% 유기농, 무添加剂)
- 캠페인 목표: 첫 구매 유도 (첫 구매 20% 할인)
- 채널: Instagram, 이메일, 랜딩 페이지

## 주의사항

### 필수 입력값

다음 4가지 입력값 중 하나라도 누락되면 스크립트 품질이 현저히 저하됩니다:
1. 타겟 고객 프로파일 (인구통계학적 특성, 심리적 특성, 행동 패턴)
2. 제품/서비스 (핵심 기능, 가치 제안, 차별화 포인트)
3. 캠페인 목표 (구매, 리드 생성, 브랜드 인지도 제고 등)
4. 채널 (이메일, SNS, 웹, 광고 중 최소 1개 이상)

### AI 슬롭 후처리

생성된 타겟 스크립트는 반드시 `moai-core:ai-slop-reviewer` 스킬을 통해 후처리해야 합니다. AI 패턴(반복적 표현, 과장된 어조, 추상적 문장)을 제거하고 실전 즉시 활용 가능한 구체적이고 명확한 스크립트로 변환합니다.
