# 이메일 시퀀스 (Email Sequence)

## 개요

한국 정보통신망법(제50조) 수신동의 요건을 완전 준수하면서 비즈니스 목표를 달성하는 이메일 시퀀스를 설계합니다.

드립 캠페인, 고객 온보딩, 재활성화, 뉴스레터 등 다양한 시퀀스 유형을 커버하며, 필수 법적 요소를 자동으로 포함합니다.

## 트리거 키워드

이메일 시퀀스, 드립 캠페인, 이메일 자동화, 뉴스레터, 온보딩 이메일, 재활성화 이메일, 이메일 마케팅, 이메일 플로우, 리드 너처링

## 실전 이메일 마케팅 패턴 (한국 시장)

이메일은 SNS보다 **타깃 도달률 38배**, 사용자 **99%가 매일 확인**하는 채널입니다. 정보통신망법 준수가 베이스, 그 위에 콘텐츠·테크닉·마케팅 3축이 유기적으로 작동해야 진짜 퍼포먼스가 나옵니다.

### 7개 핵심 패턴

**① 한국 평균 지표 (스티비 2019 → 2024 추세)**

| 지표 | B2C 평균 | B2B 평균 | 우수 캠페인 |
|---|---|---|---|
| 오픈율 | 11.7% | 25~35% | 30%+ |
| 클릭률 | 1.8% | 2.5~5% | 5%+ |
| 발송 우세 요일 | 화·수 | 화·수 | — |
| 발송 우세 시간 | 오전 8~10시 | 오전 8~10시 | — |
| 월요일 광고 메일 | 회피 권장 | 회피 권장 | — |

지표는 점진 상승 추세 — 이메일 자체에 기술 발전 + 비즈니스 활성화.

**② 콘텐츠·테크닉·마케팅 3축 (오바마 캠프 "Hey" 케이스)**

이메일은 한 축만 잘하면 안 됨. 3축이 유기적으로 작동해야:

| 축 | 목적 | 어울리는 메일 |
|---|---|---|
| **콘텐츠** | 브랜드 로열티·신뢰 | 지식 비즈니스·B2B·고관여 |
| **테크닉** | 전달율·오픈율 | 사내 공지·트랜잭션·필수 알림 |
| **마케팅** | 클릭율·랜딩 전환 | 직접 매출 영향 (퍼널 끝단) |

오바마 캠프 "Hey" 케이스가 3축 모두 최적화 — 개인화 콘텐츠 + 간결 명료 제목 + UTM 추적 + 리타게팅.

**③ 오픈율 높이는 제목 6패턴 (한국 케이스 검증)**

| 패턴 | 사례 | 결과 |
|---|---|---|
| 단순 명료 (10자 이하) | "Hey" / "안녕하세요" | 호기심 자극 |
| 놓치면 안 될 것 같은 | "32분 24초 남았습니다" | 긴급성 |
| 팩트 폭격 | "32분만에 28개 팔린 아이템" | 수치 신뢰 |
| 리스티클 | "베트남에서 성공하는 10가지 방법" | 정보 가치 |
| 네거티브 | "OO은 가방 브랜드가 아닙니다" | 오픈율 34.7% |
| 자기 고백 | "제가 회사에서 짤렸던 이야기 T..T" | 오픈율 52.4% |

**개인화 = 이름 + 17% 오픈율** ("이거 여실 거예요?" → "이하석 님, 이거 여실 거예요?"). 이모지는 +0.5배.

**④ 클릭률 높이는 5가지**

- **역삼각형 구조**: 텍스트 → 이미지 → CTA 버튼 (시선 집중)
- **미끼 효과**: 선택지 제공해 클릭 유도
- **버튼 색**: 파란색 선호 + 명암 차이
- **폰트**: 영어 Georgia, 한글 나눔고딕
- **비디오**: 재생 가능한 이미지 추가 (실제 영상 X)

**⑤ 시퀀스 D+ 표준 구조 (한국 SaaS·D2C)**

| 시점 | 목적 | CTA |
|---|---|---|
| D+0 | 웰컴·온보딩 | 핵심 기능 1개 체험 |
| D+1 | 가치 강화 | 튜토리얼·가이드 |
| D+3 | 사회적 증거 | 후기·케이스 스터디 |
| D+7 | 첫 결제 유도 | 한정 혜택 |
| D+14 | 활성 사용자화 | 고급 기능 |
| D+21 | 재참여 | 리텐션 콘텐츠 |
| D+30 | 재활성화 OR 졸업 | 인센티브 OR 수신거부 |

**⑥ 한국 정보통신망법 제50조 체크리스트**

위반 시 과태료 최대 3,000만원. 한국은 글로벌 표준(GDPR·CCPA)보다 더 엄격할 수 있음.

- [ ] 광고성 정보 수신 **명시적 사전 동의** (스팸성 옵트아웃 금지)
- [ ] 이메일 제목 시작에 `(광고)` 표시
- [ ] 본문 전송자 명칭·주소·전화번호
- [ ] 무료 수신거부 방법 안내
- [ ] 수신거부 처리 시 결과 통지
- [ ] 정기적 (2년) 수신동의 재확인
- [ ] 야간 (21시~익일 8시) 광고 발송 금지 (사전 동의 별도)

**⑦ SPF·DKIM·DMARC 세팅 = 딜리버리율 기본**

이메일 위조 검증 — 미설정 시 스팸 필터 직행. 한국 도메인은 메일플러그·스티비·메일침프 사용 시 자동 세팅 가능. 직접 SMTP 운영 시는 DNS에 TXT 레코드 3종 등록.

### 한국 이메일 발송 도구 비교

| 도구 | 강점 | 가격대 |
|---|---|---|
| 스티비 (Stibee) | 한국 최적화·UI 친화·KR 통계 | 무료~월 ₩30K |
| 메일침프 | 글로벌 표준·자동화 강력 | $0~$300+ |
| 메일플러그 | 한국 기업 대량 발송 | 월 ₩50K~ |
| 채널톡 / 카카오 채널 | 메신저 결합 CRM | 별도 |

> 💡 한국 이메일 마케팅 1위 실패 원인: **(1) 정보통신망법 미준수 → 신고 (2) 콘텐츠 없이 테크닉만 매달림 → 무관심 (3) 화·수 오전 8~10시 안 지킴**. 기본 3가지만 챙겨도 평균 이상 가능합니다.

## 워크플로우

### 1단계: 시퀀스 목적 및 타겟 확인

시퀀스 유형 선택(웰컴/온보딩, 드립 육성, 재활성화, 프로모션, 뉴스레터), 타겟 세그먼트 정의, 전환 목표 설정을 수행합니다.

### 2단계: 법적 컴플라이언스 체크 (필수)

정보통신망법 제50조 준수 필수 항목을 확인합니다:
- 수신자의 광고성 정보 수신 명시적 사전 동의
- 이메일 제목 시작 부분 `(광고)` 표시
- 본문에 전송자 명칭·주소·전화번호 명시
- 무료 수신거부 방법 안내
- 수신거부 처리 시 결과 통지
- 정기적 수신동의 여부 재확인

### 3단계: 시퀀스 구조 설계

D+0, D+1, D+3, D+7, D+14, D+21, D+30 등 단계별 이메일 발송 시점과 목적을 정의합니다. 각 단계의 핵심 메시지와 CTA를 설계합니다.

### 4단계: 이메일 본문 작성

AIDA 원칙(Attention-Interest-Desire-Action)을 적용하여 제목(30자 이내), 프리헤더(40자 이내), 본문(500자 이내 권장), CTA(버튼 1개 원칙), 푸터(전송자 정보, 수신거부 링크)를 작성합니다.

### 5단계: 성과 지표 설정 및 A/B 테스트 계획

오픈율 목표(B2B 25~35%, B2C 15~25%), 클릭률 목표(2.5~5%), 전환율 목표를 설정합니다. A/B 테스트 항목(제목, 발송 시간, CTA 버튼 문구)을 계획합니다.

## 사용 예시

**예시 1**: "SaaS 제품 신규 가입자 온보딩 이메일 7단계 시퀀스 만들어줘"
→ 법적 체크 → 시퀀스 구조 → 각 단계 이메일 초안 → 발송 스케줄

**예시 2**: "90일 이상 미활성 고객 재활성화 드립 캠페인 3단계 설계해줘"
→ 세그먼트 정의 → 재활성화 시퀀스 → 인센티브 제안 → 최종 수신거부 처리

## 출력 형식

- 시퀀스 플로우 다이어그램 (단계별 트리거·조건)
- 각 이메일 본문 초안 (제목 포함)
- 정보통신망법 컴플라이언스 체크리스트
- 성과 측정 KPI 대시보드 설계
- 수신거부 처리 프로세스 문서

## 주의사항

| 상황 | 대응 |
|------|------|
| 고객 데이터나 세그먼트 정보가 없는 경우 | 업종·목표 기반 일반적 시퀀스 구성. 실제 데이터 확보 후 세분화 권고 |
| 법적 요구사항이 불명확한 경우 | 보수적 기준(별도 광고 수신 동의)으로 설계. 법무팀 검토 권고 |
| 발송 도구가 정해지지 않은 경우 | 규모·예산 기반 도구 추천 후 설계 방향 맞춤 조정 |
