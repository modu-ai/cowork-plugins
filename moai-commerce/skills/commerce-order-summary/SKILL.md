# 채널 통합 신규 주문 요약

## 개요

스마트스토어·카페24·아임웹 채널의 신규 주문을 통합 요약합니다. 대시보드 5개를 왔다갔다 하던 수고를 1줄로 압축하는 매일 운영 루틴 스킬입니다.

**데이터 소스 (우선순위)**
1. 연결된 커머스 MCP 커넥터 — 채널 주문 데이터를 직접 조회할 수 있으면 활용
2. 사용자가 첨부한 채널별 주문 내역 내보내기 파일 (CSV·엑셀) 또는 스크린샷
3. 사용자가 붙여넣은 채널별 주문 현황 텍스트

**품질 체크리스트 요약**
채널 통합 신규 주문 1줄 요약 + .png 또는 .md 저장 확인.

---

## 트리거 키워드

신규 주문 통합, 채널 통합 주문, 스마트스토어 카페24 아임웹, 대시보드 통합, 오늘 주문, 채널별 주문 합산, 주문 1줄 요약

---

## 워크플로우

### 입력 슬롯

| 슬롯 | 필수 여부 | 기본값 | 설명 |
|------|-----------|--------|------|
| 주문 데이터 | 필수 | 없음 | 커머스 MCP 커넥터 조회 결과, 채널별 주문 내역 내보내기 파일(CSV·엑셀), 또는 스크린샷 |
| `channels` | 선택 | 전체 채널 | 특정 채널만 조회 시 명시 (smartstore, cafe24, imweb) |
| `date` | 선택 | 오늘 날짜 (자동) | 조회 기준 날짜 |

### 처리 단계

1. 주문 데이터 수집 (커넥터 조회 또는 첨부 파일·스크린샷 분석)
2. 3채널 신규 주문 데이터 정리 — 누락 채널은 "데이터 없음" 표기
3. 채널별 + 합산 집계
4. 1줄 통합 요약 생성
5. .md (또는 .png 스크린샷) 저장

> **ai-slop-reviewer**: 수치 데이터 스킬이므로 후처리 제외. 주문 건수·금액은 원본 데이터 보존.

### 데이터가 부족할 때

일부 채널의 주문 데이터가 없으면 해당 채널을 "데이터 없음"으로 표기하고 확보된 채널만 합산합니다. 주문 데이터에 접근할 방법이 전혀 없으면, 채널 관리자별 주문 내역 내보내기 위치(스마트스토어 판매관리 / 카페24 주문관리 / 아임웹 주문 목록)를 안내합니다.

## 사용 예시

**예시 1 — 기본 호출 (파일 첨부)**
> "오늘 주문 통합해줘" (채널별 주문 내역 내보내기 파일 첨부)

```
첨부 데이터 분석 → 오늘 날짜 기준 정리
출력:
[2026-05-12 신규 주문 통합]
스마트스토어: 18건 · 카페24: 9건 · 아임웹: 5건 = 합계 32건 (₩4,820,000)
→ order-summary-20260512.md 저장
```

**예시 2 — 특정 채널만**
> "카페24 주문만 보여줘"

```
첨부 데이터에서 channels: ["cafe24"]만 정리
출력: 카페24 채널 신규 주문 요약
```

**예시 3 — 스크린샷 입력**
> "채널별 주문 화면 스크린샷이야, 통합해줘"

```
스크린샷에서 수치 추출 → 3채널 신규 주문 통합 1줄 → .md 저장
```

```markdown
| 카페24 | N건 | ₩N,NNN,NNN |
| 아임웹 | N건 | ₩N,NNN,NNN |
| **합계** | **N건** | **₩N,NNN,NNN** |

```

저장 경로: `작업_폴더/order-summary-YYYYMMDD.md`

## 이 스킬을 사용하지 말아야 할 때

- 주문 외 문의·트렌드·ROAS 등 종합 매장 현황이 필요한 경우 → `moai-commerce:commerce-morning-brief` 사용
- 광고 채널(Facebook Ads, Google Ads) 전환 데이터가 필요한 경우 → 광고 분석 스킬 사용
- MCP 커넥터로 직접 조회하려는데 인증이 완료되지 않은 경우 → `moai-core:mcp-connector-setup` 먼저 실행
- 외부 뉴스·시장 정보가 필요한 경우 → `moai-business:daily-briefing` 사용
