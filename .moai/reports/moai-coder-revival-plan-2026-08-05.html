1배경 — 왜 다시 코더인가

코더 플러그인은 한 번 삭제된 이력이 있다 — 커밋 78eda1c "remove coder plugin — cowork-only marketplace (20→17)". 이전엔 moai-coder(→ moai로 개명) + LSP/MCP 도구 형태였다.

지금 다시 살리는 이유: 비개발자가 랜딩 페이지를 직접 만들어 배포하려는 수요가 생겼고, Vercel/Cloudflare/Higgsfield 모두 공식 MCP를 제공하므로 — 과거처럼 직접 도구를 짜는 무거운 플러그인이 아니라 공식 MCP를 조합하는 얇은 워크플로 플러그인으로 재설계하면 비개발자에게 충분히 쓸모있고 유지비도 거의 0이다. 정적 랜딩에 한정해 복잡도를 최소화했다(사용자 정정).

2핵심 원칙 — 공식 MCP 우선

CLAUDE.local.md에 명시된 원칙(2026-08-05 추가): 외부 서비스 연동 시 공식 MCP가 있으면 무조건 그것을 쓰고, 플러그인 안에 Python/Node 클라이언트를 직접 구현하지 않는다. 이 계획의 모든 설계는 이 원칙에서 출발한다. 직전 사례(R2 업로드를 boto3/httpx로 짜다가 CF 공식 MCP로 전면 회수)의 교훈이다.

도메인 구입 — Vercel + Cloudflare 둘 다 지원

Vercel은 도메인 직접 구입(네임서버 자동, all-in-one). Cloudflare Registrar는 원가(at-cost) 등록 + Registrar API(가용성·등록)를 CF API MCP 경유로 노출. → 도메인 연결 스킬(구입+연결)을 워크플로에 포함.

확인 필요(SPEC run): CF Registrar API 프로그래매틱 등록이 계정 등급(과거 Enterprise 한정)에 따라 제한될 수 있음 · Vercel MCP가 도메인 구입 결제까지 노출하는지(대시보드 전용일 수 있음) — 구입 불가 쪽은 "소유 도메인 연결"로 폴백.

설정 예시(플러그인 .mcp.json의 mcpServers 뼈대 — 각 항목은 SPEC에서 확정):

{
  "mcpServers": {
    "vercel":         { "url": "https://mcp.vercel.com" },
    "cloudflare-api": { "url": "https://mcp.cloudflare.com/mcp" },
    "higgsfield":     { "type":"url", "url":"https://mcp.higgsfield.ai/mcp" }
  }
}

→ Higgsfield·CF 설정은 이미 moai-designer/.mcp.json에서 검증된 형태를 참조(중복 회피).

4플러그인 구조 (moai-coder)

직접 구현 코드는 거의/전혀 없고, 설정 + 워크플로 스킬 + 문서가 본체다.

  • .claude-plugin/plugin.json — displayName(「코더」/「랜딩 빌더」, 사용자 결정). version 1.0.0.
  • .mcp.json — 위 3개 공식 MCP 묶음.
  • skills/ — 비개발자용 워크플로 스킬: 자산생성·랜딩 조립·배포·도메인 연결(구입+연결) (아래 §5).
  • README.md / CONNECTORS.md — 각 서비스 무료 가입·OAuth/토큰 발급 안내(비개발자용, 스크린샷 단계).

6기존 플러그인과 조합 (중복 금지)

Higgsfield — moai-designer / moai-media 가 소유

Higgsfield MCP는 이미 moai-designer/.mcp.json에 있고, 생성 계약은 moai-media:media-higgsfield-core가 갖는다. 코더 플러그인은 재구현/재설정하지 않는다 — 위임. .mcp.json에 higgsfield를 넣되 "생성 실행은 moai-media 스킬로 위임"을 문서화.

Cloudflare — 소셜 포스터 IMAGEHOST SPEC 과 공유

진행 중 SPEC-THREADS-POSTER-IMAGEHOST-001(Architecture A)도 CF MCP를 플러그인 .mcp.json에 추가. 코더가 같은 CF MCP를 쓰므로 — 사용자는 CF MCP에 한 번 OAuth 로그인하면 양쪽이 다 쓴다(원격 MCP는 클라이언트별 독립이라 설정 중복은 무해).

9위험·대응 · 범위 외

위험 — 비개발자의 OAuth/토큰 부담 (3개 서비스)

v1(5개)보다 가벼워졌지만 여전히 Vercel·CF·Higgsfield 각각 가입·OAuth/토큰 필요. 대응: CONNECTORS.md 스크린샷 단계 안내 + "처음엔 Vercel 1개만" 점진 온보딩. Higgsfield는 이미 moai-designer 쓰면 중복 가입 없음.

위험 — 무료 한도·상업 제한·도메인 비용

Vercel Hobby 상업 제한, CF R2 10GB, Higgsfield 크레딧, 도메인은 연간 비용 발생. 대응: 한도 가시화 + 유료 전환 가이드. 도메인 구입 전 비용 안내 필수.

위험 — 공식 MCP 의존도

MCP 장애/스펙 변경 시 영향. 대응: 각 스킬에 "MCP 미연결 시 수동 안내" 폴백(moai-designer 기존 패턴 — 빈 슬롯 명시, 저품질 대체 금지).
