# 슬라이드 정량 QA 루브릭 — 6카테고리 가중합 + hard-fail

발표급 슬라이드가 아마추어 슬라이드와 갈리는 지점을 **사람이 보지 않고도 1차로 자동 채점**하기 위한 규칙 세트입니다. doc-html-slide는 단일 파일 HTML(DOM)을 렌더하므로, 문서형 슬라이드(pptx) 채점에서 흔히 쓰는 python-pptx 파싱 관행을 **HTML/DOM 파싱·렌더 검사**로 옮겨 적용합니다.

> **핵심 원칙 — 임계값은 상수가 아니다.** 아래 모든 수치(폰트 하한, 6x6, 색상 수, 액션타이틀 길이, 명도대비)는 업계 컨센서스로 수렴한 **기본값**일 뿐 공식 규정값이 아닙니다. 브랜드·청중·발표 환경(온라인/오프라인)에 따라 조정되어야 하며, 채점기는 이 값을 설정 파일(예: `qa-config.json`)로 오버라이드할 수 있게 구현합니다. **고정 상수로 하드코딩하지 마십시오.**

---

## 채점 구조 — 3단계

1. **DOM 구조 파서** — 슬라이드마다 (a) 제목 텍스트, (b) 본문 텍스트 전체, (c) 모든 텍스트 노드의 computed `font-size`/`font-family`/`color`, (d) 모든 요소의 `getBoundingClientRect()`, (e) 인라인 SVG 차트의 시리즈 수·범례 존재 여부를 추출합니다.
2. **규칙 채점** — 아래 34개 기준을 각각 독립 함수로 구현해 슬라이드별 pass/fail과 근거 수치를 반환합니다.
3. **종합 스코어** — 규칙을 6카테고리로 그룹핑해 **가중합 점수**를 산출하고, hard-fail 규칙은 감점이 아니라 **즉시 반려**로 처리합니다.

## 6 카테고리 가중합

| 카테고리 | 포함 기준(번호) | 채점 관점 |
|---|---|---|
| **구조(structure)** | 1·2·3·4·5·6·7·8 | 액션타이틀·원 메시지·불릿 상한 |
| **타이포(typography)** | 9·10·11·12·13·28 | 폰트 하한·종류 상한·오버플로 |
| **컬러(color)** | 14·15·16·30 | 팔레트 수·강조 비율·명도대비·의미 일관성 |
| **정렬(alignment)** | 20·21·22·23·27 | 그리드 스냅·여백·화이트스페이스·표 밀도 |
| **데이터시각화(data-viz)** | 17·18·19·29·32·33 | 데이터-잉크·직접 라벨링·차트 정크·아이콘 의미 |
| **신뢰성(trust)** | 24·25·26·31·34 | 출처 라인·페이지 번호·발화 시간·대체텍스트·산출물 경계 |

**합격선**은 6카테고리 가중합 기준을 두되(예: 90/100), 이 합격선 자체가 **캘리브레이션으로 조정되는 값**이며 고정 상수가 아닙니다. 카테고리 가중치·합격선은 프로젝트 설정에서 재정의합니다.

## Hard-fail 티어 (즉시 반려)

아래 8개는 가중합 감점이 아니라 **한 건이라도 걸리면 즉시 반려**입니다(발표급 아님 → 고쳐서 다시).

1. **본문 폰트 하한 미달** — 본문 텍스트가 설정된 하한(기본 24pt 상당, 온라인 전용 덱은 18pt로 하향 설정 가능) 미만.
2. **수치 슬라이드 출처라인 부재** — 숫자·차트·표가 있는데 `출처:`/`자료:`/`Source:` 텍스트 노드 없음.
3. **명도대비 WCAG 4.5:1 미달** — 본문 텍스트-배경 대비가 4.5:1 미만(큰 텍스트 3:1).
4. **텍스트 오버플로** — 텍스트 요소의 `scrollHeight > clientHeight`(박스 밖으로 넘침) 또는 자동 축소로 폰트가 하한 미만이 됨.
5. **3D 차트 효과** — SVG/CSS에 원근·`rotateX/Y`·입체 그림자 등 3D 차트 장식.
6. **그리드 정렬 편차 초과** — 동일 역할 요소(제목/푸터)의 좌표 편차가 슬라이드 너비의 허용 오차(기본 1%)를 초과.
7. **아이콘 돌려쓰기** — 같은 아이콘이 4회 이상 쓰임(#32), 또는 `icon_reason`이 없거나 그 문구의 행동과 대응하지 않음(#33).
8. **제작 메타 노출** — 슬라이드 바깥에 제작 메타·디버그 텍스트가 렌더됨(#34). 런타임 UI(카운터·진행바·발표자 노트·접근성 라이브 영역)는 해당하지 않는다.

> hard-fail 임계값도 모두 설정 오버라이드 대상입니다 — 예컨대 온라인 아카이브 덱은 폰트 하한을 18pt로 낮춰 재정의할 수 있습니다.

### 아이콘 근거 판정 — #33 측정 보칙

**필드가 채워졌는지가 아니라 근거가 성립하는지를 본다.** 존재 여부만 검사하면 `{"icon":"paper-plane","icon_reason":"아이콘을 넣어야 해서"}` 가 통과한다 — 그 값은 아무것도 지목하지 않으며, 이 기준이 막으려던 바로 그 상태다.

**[HARD] 렌더 HTML에 `data-icon`과 슬롯 식별자를 남긴다.** 그러지 않으면 DOM만 보고는 어느 `<svg>`가 어느 슬롯의 어떤 아이콘인지 알 수 없어 #32·#33을 잴 수 없다. 렌더 시 아이콘 요소에 `data-icon="<정규화된 icon ID>"` `data-slot="<슬라이드id>-<인덱스>"`를 붙인다. 채점기는 그 속성과 `deck.json`의 `icons`를 대조한다.

채점기는 슬롯마다 세 값을 **나란히** 출력한다:

```
슬롯   : "점검만 요청합니다"
동사   : 요청하다 / 점검하다
아이콘 : clipboard-check
근거   : "점검 결과를 표시해 남기는 행위"      → 대응 성립
```

**fail로 판정하는 근거**

| 유형 | 예 |
|---|---|
| 동어반복 | "아이콘이 필요해서", "이 자리에 맞아서", "어울려서" |
| 아이콘 이름만 되풀이 | 아이콘이 `folder`인데 근거가 "폴더라서" |
| 슬롯 문구를 그대로 복사 | 근거 칸에 문구가 그대로 들어감 |
| 문구의 어느 말과도 이어지지 않음 | "색이 흐려집니다" ↔ `paper-plane` ↔ "전달을 뜻해서" |

**pass로 판정하는 근거**: 문구가 시키는 **행동이나 상태**를 지목하고, 그것이 아이콘의 통상적 의미와 이어진다. 판정은 사람이 읽고 납득하는 수준이면 충분하다 — 사전적 일치를 요구하지 않는다.

**같은 의미로 반복하는 아이콘에는 별도 상한을 둔다 — 예외가 아니라 다른 상한이다.** 체크리스트 네 항목에 체크 표시를 네 번 쓰는 것은 돌려쓰기가 아니라 일관된 표기다. 다만 "역할이 같으니 무제한"으로 열어 두면 `icon_reason`에 같은 일반론을 복사해 넣어 상한을 통째로 우회할 수 있다.

`icon_role`을 선언한 슬롯에 한해 상한을 **6회**로 올린다. 그 이상은 역할이 같아도 fail이다.

| `icon_role` | 뜻 | 예 |
|---|---|---|
| `status` | 상태 표시 | 완료·진행중·차단 |
| `nav` | 순서·이동 | 단계 번호, 다음/이전 |
| `legend` | 범례 | 차트 계열 표시 |

- **`icon_role`은 위 세 값만 쓴다.** 자유문장이 아니다 — 자유문장이면 무엇이든 "같은 역할"이라 주장할 수 있다.
- 역할이 섞이면 상한 완화를 받지 못한다. 같은 폴더 아이콘이 한 슬롯에서는 "자료 보관", 다른 슬롯에서는 "분류"를 뜻하면 그건 돌려쓰기다.
- `icon_role`이 없는 슬롯은 기본 상한 **3회**를 적용한다.

**비워 둔 슬롯은 fail이 아니다.** 스키마가 "마땅한 것이 없으면 비운다"를 허용하므로, 아이콘이 없는 슬롯은 이 기준의 대상이 아니다. 채워 놓고 근거가 성립하지 않는 것만 fail이다.

### 제작 메타 판정 — #34 측정 보칙

**슬라이드 바깥에 텍스트가 있다는 사실만으로 반려하지 않는다.** 덱 런타임은 슬라이드 밖에 UI를 렌더하는 것이 정상이며, 그것까지 잡으면 이 스킬의 정식 샘플과 표준 런타임이 스스로 hard-fail한다.

**허용 — 반려 대상 아님**

| 요소 | 예 |
|---|---|
| 슬라이드 카운터 | `#counter` (`3 / 8`) |
| 진행 표시 | `#progress` |
| 발표자 노트 레이어 | `#notes-layer` (토글로 감춰지는 발표자 전용) |
| 접근성 라이브 영역 | `aria-live` 영역, 스크린리더 전용 텍스트 |
| 인쇄 전용/화면 전용 전환 문구 | `@media print`로 감춰지는 조작 안내 |

이들은 `references/html-runtime.md`가 정의하는 **덱 조작 UI**다. 판정 대상이 아니다.

**반려 — 제작 메타·디버그**

| 무엇 | 예 |
|---|---|

### SVG 실효 크기 — #9 측정 보칙

인라인 SVG·mermaid 도식의 텍스트는 **저작 시점 `font-size`가 아니라 화면에 찍히는 크기로 판정한다.** `object-fit:contain`·`width:100%`로 배치된 SVG는 컨테이너에 맞춰 축소되며, 그 배율만큼 글자도 작아진다.

```
배율   = min(렌더폭 / viewBox폭, 렌더높이 / viewBox높이)
실효px = 노드 computed font-size × 배율
실효pt = 실효px × 0.75      // 1280px 슬라이드 기준
```

가로로 납작한 도식일수록 배율이 급격히 떨어진다 — 가로세로비 **8:1을 넘으면 배율이 0.65 아래로 내려가** 26px 라벨이 17px(12.7pt)로 찍힌다. 실효 크기가 하한에 못 미치면 **글자를 키우는 것이 아니라 도식을 다시 배치한다**(가로 흐름을 2단으로 접기, 노드 수 줄이기, 세로 흐름으로 전환). 폰트만 키우면 도식이 컨테이너를 넘는다.

> H/S = hard(즉시 반려) / soft(가중합 감점). hard 표기는 기본 설정 기준이며, 온라인·아카이브 프로파일에서는 일부를 soft로 재분류할 수 있습니다.
