# 채널 운영 체계 (youtube-channel-ops)

> `moai-youtuber` | 채널 살림 — 리듬·포트폴리오·목표

## 개요

유튜브에서 대부분의 채널이 멈추는 이유는 아이디어 고갈이 아니라 **운영 부담**입니다. 이 스킬은
"한 편 잘 만들기"가 아니라 **계속 낼 수 있는 구조**를 설계합니다. 지속 가능한 업로드 리듬을 먼저
정하고, 그 리듬에 맞는 시리즈 조합을 짜고, 분기 목표를 관측 가능한 지표로 바꿉니다.

## 트리거 키워드

유튜브 채널 운영, 업로드 주기, 업로드 리듬, 시리즈, 콘텐츠 포트폴리오, 채널 목표, 경쟁 채널,
벤치마크, 운영 캘린더, 번아웃, 채널 성장, 구독자 목표

## 작업 흐름

### 1. 현재 상태 확인

먼저 지금 상태를 사실로 확정합니다 — 추정하지 않습니다.

- 채널 주제와 대상 시청자, 현재 업로드 실적(최근 몇 편을 어떤 간격으로 냈는지)
- 한 편당 실제 투입 시간(기획·촬영·편집·썸네일 각각)
- 혼자인지, 편집자가 있는지, 외주가 있는지

MCP가 연결돼 있으면 `list_my_videos`로 최근 업로드 이력을 직접 읽어 확인합니다.
연결 전이라면 사용자에게 물어 채웁니다.

### 2. 지속 가능한 리듬 산출

투입 시간과 가용 시간에서 **역산**합니다. "주 2회가 좋다"는 통념이 아니라, 이 사람이 실제로
버틸 수 있는 간격을 찾습니다.

| 축 | 확인할 것 |
|---|---|
| 가용 시간 | 주당 채널에 쓸 수 있는 총 시간 |
| 편당 원가 | 기획 + 촬영 + 편집 + 썸네일 + 발행 |
| 여유분 | 몸이 아프거나 일이 몰릴 주를 위한 완충 |

여유분 없이 100% 채운 계획은 두 달을 못 갑니다. **가용 시간의 70% 선에서 리듬을 잡고**,
남는 30%를 밀린 편·재촬영·휴식에 배정합니다.

### 3. 시리즈 포트폴리오 설계

한 채널을 성격이 다른 시리즈로 나눠 부담을 분산합니다.

| 유형 | 역할 | 제작 부담 |
|---|---|---|
| 기둥 시리즈 | 채널 정체성을 대표. 검색·추천 유입의 축 | 높음 |
| 반복 포맷 | 같은 틀에 내용만 갈아 끼우는 형태 | 낮음 |
| 라이브 | 실시간 소통, 편집 부담이 거의 없음 | 낮음 |
| 실험 | 새 주제 탐색 — 실패해도 되는 자리 | 중간 |

부담이 높은 것만으로 채우지 않는 게 핵심입니다. 라이브와 반복 포맷이 리듬을 지켜 줍니다.

### 4. 경쟁 채널 벤치마크

같은 주제의 채널을 살펴 **따라 할 것과 피할 것**을 구분합니다. 판단 근거는 반드시 관측된
사실(공개된 업로드 간격·제목 패턴·영상 길이·구성)로 적고, 조회수 추정이나 수익 추정처럼
확인할 수 없는 값은 쓰지 않습니다.

MCP 연결 시 `search_videos`로 조회하되, 검색은 할당량을 크게 쓰므로 **한 번 조회한 결과를
재사용**하고 같은 검색을 반복하지 않습니다.

### 5. 분기 목표

목표는 "구독자 늘리기" 같은 소망이 아니라 **관측 가능한 문장**으로 적습니다.

- 나쁜 목표: 채널을 키운다
- 좋은 목표: 기둥 시리즈를 격주로 빠짐없이 내고, 노출 클릭률이 지금보다 나아진 상태를 유지한다

## 산출물

- 채널 운영 캘린더 (리듬 + 시리즈 배치 + 완충 주)
- 시리즈 포트폴리오 표 (유형·주기·제작 부담·담당)
- 분기 목표와 점검 시점
- 벤치마크 요약 (따라 할 것 / 피할 것, 근거 포함)

## 체인 연결

```
youtube-channel-ops (운영 체계)
  → moai-marketer:marketing-youtube-podcast-planner (편별 기획·대본)
  → youtube-production 또는 youtube-live-ops (제작·방송)
  → youtube-publish-ops (발행)
  → youtube-analytics-review (성과 → 다음 분기 운영 체계로 되먹임)
```

텍스트 산출물은 `moai-coworker:ai-slop-reviewer`로 검수하고, 한국어 최종본은
`moai-writer:korean-humanize`로 다듬어 마무리합니다.

## 주의

- 실적·조회수 등 숫자는 **확인된 값만** 적습니다. 추정치를 쓸 때는 추정임을 문장에 남깁니다.
- 남의 채널 콘텐츠를 그대로 베끼는 기획은 제안하지 않습니다 — 구조를 참고하되 소재는 새로 잡습니다.
- 운영 계획이 사용자의 가용 시간을 넘어서면, 계획을 줄이자고 먼저 말합니다.
