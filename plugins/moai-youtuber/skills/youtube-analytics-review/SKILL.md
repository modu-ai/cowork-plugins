# 성과 리뷰 (youtube-analytics-review)

> `moai-youtuber` | 숫자 → 원인 → 다음 액션

## 개요

"조회수가 안 나온다"는 하나의 문제가 아닙니다. **노출이 안 된 것**, **노출은 됐는데 클릭이
안 된 것**, **클릭은 됐는데 금방 나간 것**은 원인도 처방도 완전히 다릅니다. 이 스킬은 먼저
어느 단계에서 새는지 특정하고, 그 단계에만 처방을 냅니다.

## 트리거 키워드

성과, 분석, 조회수, 노출, 클릭률, CTR, 시청 지속, 평균 시청 시간, 이탈, 유입 경로,
구독 전환, 리뷰, 대시보드

## 진단 순서 — 위에서부터 좁힌다

```
노출이 적다        → 주제·검색어·재생목록 문제 (콘텐츠 이전 단계)
  ↓ 노출은 충분
클릭이 안 된다     → 썸네일·제목 문제
  ↓ 클릭은 됨
초반에 나간다      → 오프닝 길이·약속 불일치
  ↓ 초반 통과
중간에 나간다      → 특정 구간의 늘어짐
  ↓ 끝까지 봄
구독이 안 된다     → 다음 행동 안내 부재
```

**한 번에 하나씩만 고칩니다.** 썸네일과 제목과 오프닝을 동시에 바꾸면 무엇이 효과였는지
알 수 없습니다.

## 단계별 처방

| 새는 지점 | 확인할 것 | 처방 |
|---|---|---|
| 노출 부족 | 유입 경로 구성 · 검색어 | 주제를 검색되는 표현으로 · 재생목록 정비 |
| 클릭 부족 | 노출 클릭률 · 목록에서의 모습 | 썸네일 문구 대비 · 제목 앞부분 재작성 |
| 초반 이탈 | 도입부 유지 곡선 | 오프닝 단축 · 첫 문장에서 약속 명시 |
| 중간 이탈 | 유지 곡선의 급락 지점 | 그 구간 컷 편집 · 인서트 보강 |
| 구독 미전환 | 구독 발생 위치 | 영상 끝에 다음 볼 것 제시 · 최종 화면 |

## MCP 연동 (연결 시)

```
channel_report          기간별 채널 지표
video_report            영상별 지표
traffic_source_report   유입 경로 구성
audience_retention      유지 곡선 (이탈 지점 특정)
```

MCP 미연결 상태에서는 사용자가 유튜브 스튜디오에서 확인할 화면과 **어떤 숫자를 적어 오면
되는지**를 안내하고, 받은 숫자로 진단합니다.

## 비교 기준 잡기

숫자 하나만 보면 판단할 수 없습니다. 반드시 비교 대상을 함께 둡니다.

- 같은 채널의 최근 영상들과 비교 (가장 신뢰할 수 있는 기준)
- 같은 시리즈 안에서 비교
- 업로드 후 경과 기간을 맞춰서 비교 (어제 올린 영상과 한 달 된 영상을 비교하지 않습니다)

## 산출물

- 어느 단계에서 새는지 특정한 진단
- 근거가 된 숫자 (출처: 어느 보고서의 어떤 값인지 명시)
- 다음 영상에 적용할 액션 (하나만)
- 다음 점검 시점과 볼 지표

## 주의

- **확인하지 않은 숫자를 말하지 않습니다.** MCP도 없고 사용자가 준 값도 없으면, 무엇을
  확인해야 하는지 알려 드리고 거기서 멈춥니다. 추정 수치로 진단하지 않습니다.
- 표본이 적은 영상(올린 지 얼마 안 된 영상)으로 결론을 내지 않습니다.
- 알고리즘의 내부 동작을 단정하지 않습니다 — 관측된 지표와 그로부터의 추론을 구분해 씁니다.
- 액션은 다음 영상에서 검증 가능한 것으로 하나만 냅니다. 목록으로 쏟아내면 아무것도 검증되지 않습니다.
