# 라이브 방송 운영 (youtube-live-ops)

> `moai-youtuber` | 방송 전 · 방송 중 · 방송 후

## 개요

라이브는 되돌릴 수 없습니다. 송출이 끊기거나 소리가 안 나간 채로 진행된 방송은 복구가
불가능합니다. 그래서 이 스킬은 **사전 점검을 가장 무겁게** 다루고, 방송 중에는 판단을
단순하게 만들고, 종료 후에는 자산으로 남기는 데 집중합니다.

## 트리거 키워드

유튜브 라이브, 생방송, 실시간 방송, 스트리밍, 송출, 스트림 키, 큐시트, 실시간 채팅,
슈퍼챗, 대기실, 예약 방송, 다시보기, 방송 사고

## 1단계 — 방송 전

### 사전 점검표

방송 시작 전에 아래를 순서대로 확인합니다. 하나라도 미확인이면 **시작하지 않습니다.**

| 구분 | 점검 항목 |
|---|---|
| 송출 | 인코더가 스트림 키를 물고 있는가 · 업로드 대역폭이 안정적인가 · 유선 연결인가 |
| 소리 | 마이크 입력 레벨이 잡히는가 · 배경음이 저작권에 걸리지 않는가 · 모니터링 이어폰 |
| 화면 | 해상도·프레임 설정 · 알림창 차단 · 공유할 화면에 개인정보가 없는가 |
| 방송 정보 | 제목·설명·공개 범위·아동용 여부·예약 시각 |
| 대비 | 끊겼을 때 어디에 공지할지 · 대체 진행자 유무 · 예비 회선 |

**개인정보 노출이 라이브에서 가장 흔한 사고입니다.** 화면 공유 전에 브라우저 탭·알림·바탕화면
파일명·메신저 창을 반드시 함께 점검합니다.

### 방송 생성 (MCP 연결 시)

```
create_broadcast   제목·시작 시각·공개 범위 지정
  → bind_stream    인코더 스트림 연결
  → transition_broadcast: testing   (미리보기로 화면·소리 확인)
  → transition_broadcast: live      (실제 송출 시작)
```

MCP가 아직 연결되지 않았다면 같은 순서를 **유튜브 스튜디오 화면에서 수동으로** 진행하도록
안내하고, 각 단계에서 무엇을 확인해야 하는지 함께 알려 드립니다.

## 2단계 — 방송 중

### 큐시트

방송 중에는 복잡한 문서를 읽을 수 없습니다. 큐시트는 **한 화면에 들어가야** 합니다.

| 구간 | 내용 | 목표 시간 |
|---|---|---|
| 오프닝 | 인사 · 오늘 다룰 것 한 줄 | 짧게 |
| 본론 | 구간별 주제 (구간마다 한 줄) | 구간별 배분 |
| 소통 | 채팅 질문 받기 | 중간에 한 번 이상 |
| 마무리 | 요약 · 다음 방송 예고 · 구독 안내 | 짧게 |

지연 도착하는 시청자를 위해 **본론 진입 직전에 오늘 주제를 한 번 더** 말하는 구간을 넣습니다.

### 실시간 채팅

- 질문은 모아서 구간 단위로 답합니다. 오는 대로 답하면 진행이 무너집니다.
- 반복 질문은 고정 메시지로 올려 같은 답을 여러 번 하지 않게 합니다.
- 악성 메시지는 논쟁하지 않고 즉시 숨김·차단합니다. 방송 중 해명은 판을 키웁니다.

MCP 연결 시 `read_live_chat`으로 질문을 모으고, `send_live_chat`으로 공지를 올리고,
`moderate_live_chat`으로 처리합니다.

### 사고 대응

| 증상 | 즉시 할 일 |
|---|---|
| 송출 끊김 | 인코더 재시작 → 같은 방송에 재연결. 다른 채널(SNS)에 상황 공지 |
| 소리 안 나감 | 채팅으로 확인 요청 → 입력 장치 전환 → 안 되면 방송 종료 후 재개설 |
| 화면 오노출 | 즉시 장면 전환 → 방송 종료 후 다시보기 해당 구간 편집 또는 비공개 |

## 3단계 — 방송 후

```
transition_broadcast: complete   (방송 종료)
  → 다시보기 제목·설명 정리 (라이브 제목 그대로 두지 않습니다)
  → 챕터 표시 추가 (구간별 시작 시각)
  → 하이라이트 구간 표시 → youtube-shorts-repurpose로 넘김
  → 채팅에서 나온 질문 중 답 못 한 것 → 커뮤니티 탭 후속 (youtube-community-cs)
```

라이브 다시보기는 **제목과 설명을 정리하는 순간 검색 자산이 됩니다.** 이 단계를 건너뛰면
좋은 방송도 묻힙니다.

## 산출물

- 사전 점검표 (체크 완료 여부 포함)
- 한 화면 큐시트
- 방송 중 채팅 대응 지침
- 종료 후 정리 목록 (제목·설명·챕터·하이라이트·후속 질문)

## 주의

- **MCP 미연결 상태에서 "방송을 켰다"고 말하지 않습니다.** 준비물과 절차만 제공하고, 실제
  송출은 사용자가 확인한 것을 보고받아 진행합니다.
- 배경음악은 저작권 문제가 실시간으로 잡힙니다 — 출처가 확실한 음원만 씁니다.
- 방송 시각은 사용자의 시간대 기준으로 적고, 예약 시각은 방송 전에 다시 한 번 확인합니다.
