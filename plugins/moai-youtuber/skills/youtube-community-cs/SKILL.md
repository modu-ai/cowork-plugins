# 댓글·커뮤니티 운영 (youtube-community-cs)

> `moai-youtuber` | 댓글 분류 · 답글 · 커뮤니티 탭

## 개요

댓글은 응대 업무이면서 동시에 **가장 값싼 소재 창고**입니다. 이 스킬은 댓글을 종류별로 갈라
처리 방식을 다르게 하고, 그 과정에서 나온 질문을 다음 영상 기획으로 넘깁니다.

## 트리거 키워드

댓글, 답글, 고정 댓글, 커뮤니티 탭, 악플, 스팸, 차단, 신고, 시청자 질문, 소통

## 댓글 분류

| 종류 | 처리 |
|---|---|
| 질문 | 답글. 반복되면 고정 댓글로 승격 |
| 호의·응원 | 짧게 감사. 전부 답할 필요 없음 |
| 지적·정정 | 사실이면 인정하고 고정 댓글로 정정 공지. 아니면 근거를 들어 한 번만 답 |
| 소재 제안 | 목록에 모아 기획으로 넘김 |
| 악성·인신공격 | 답하지 않음. 숨김 또는 차단 |
| 스팸·사기 | 즉시 삭제·신고. 링크는 절대 클릭하지 않음 |

## 답글 원칙

- **짧게.** 긴 답글은 다른 댓글을 안 보이게 만듭니다.
- 같은 문장을 복사해 여러 댓글에 붙이지 않습니다. 형식적인 답은 안 다느니만 못합니다.
- 사실 관계가 확실하지 않으면 단정하지 않고, 확인 후 다시 답하겠다고 적습니다.
- 개인 정보(연락처·주소·계좌)를 댓글에서 주고받지 않습니다.

## 반복 질문 → 고정 댓글

같은 질문이 세 번 이상 나오면 개별 답글을 멈추고 **고정 댓글**로 올립니다. 고정 댓글은
설명란보다 눈에 잘 띄어서, 반복 응대를 크게 줄입니다.

```
질문 반복 감지
  → 고정 댓글 작성 (질문 + 답 한 묶음)
  → 설명란에도 같은 내용 추가
  → 그래도 반복되면 → 다음 영상 소재로 승격
```

## 악성 댓글 대응

가장 중요한 원칙은 **공개 논쟁을 하지 않는 것**입니다. 반박은 상대에게 노출을 주고, 다른
시청자에게는 채널의 인상을 나쁘게 만듭니다.

| 상황 | 대응 |
|---|---|
| 단순 비방 | 숨김. 답하지 않음 |
| 반복 가해 | 채널 차단 |
| 협박·명예훼손·허위사실 | 화면 보존(캡처) 후 신고. 필요 시 moai-lawyer로 넘김 |
| 사실에 기반한 비판 | 감정을 빼고 사실만 인정. 개선하겠다고 짧게 |

**증거 보존을 먼저, 삭제는 그다음입니다.** 지우고 나면 신고 자료가 사라집니다.

## 커뮤니티 탭

업로드 사이 간격을 메우는 자리입니다. 부담이 적은 형식으로 씁니다.

- 다음 영상 예고 (촬영 중 사진 한 장)
- 시청자 투표 (다음 주제 고르기 — 소재 발굴과 참여를 동시에)
- 짧은 근황·질문 받기
- 지난 영상 정정 공지

## MCP 연동 (연결 시)

```
list_comments      최근 댓글 수집 → 분류
reply_comment      답글 등록
moderate_comment   숨김·삭제 처리
```

MCP 미연결 상태에서는 사용자가 붙여넣은 댓글 목록을 분류하고 **답글 초안**을 만들어 드립니다.
등록은 사용자가 직접 합니다 — 올리지 않은 것을 올렸다고 말하지 않습니다.

## 산출물

- 댓글 분류 결과 (종류별)
- 답글 초안 (질문·정정 건별)
- 고정 댓글 문안
- 다음 영상 소재 후보 목록
- 커뮤니티 탭 게시물 초안

## 주의

- 답글은 사용자 이름으로 나갑니다. **등록 전에 반드시 확인받습니다.**
- 시청자를 판단하거나 비꼬는 표현을 쓰지 않습니다.
- 법적 다툼으로 번질 수 있는 사안(협박·허위사실·저작권 주장)은 답글 초안을 만들지 않고
  `moai-lawyer`로 넘깁니다.
