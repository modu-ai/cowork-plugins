# 발행 운영 (youtube-publish-ops)

> `moai-youtuber` | 업로드 · 메타데이터 · 재생목록 · 예약

## 개요

영상을 다 만들고 **발행에서 대충 하면** 그동안의 작업이 묻힙니다. 설명란이 비어 있고 챕터가
없고 재생목록에 안 들어간 영상은, 올린 그 주에만 보이고 끝납니다. 이 스킬은 발행을
체크리스트로 만들어 빠뜨림을 없앱니다.

## 트리거 키워드

업로드, 발행, 설명란, 태그, 챕터, 타임스탬프, 재생목록, 예약 발행, 공개 설정, 자막,
카드, 최종 화면, 아동용

## 발행 체크리스트

| 순서 | 항목 | 빠뜨리면 |
|---|---|---|
| 1 | 제목 | 검색·클릭이 모두 죽음 |
| 2 | 썸네일 | 노출돼도 클릭이 안 됨 |
| 3 | 설명란 첫 줄 | 목록에서 보이는 유일한 설명 |
| 4 | 챕터 | 긴 영상의 이탈이 커짐 |
| 5 | 재생목록 | 다음 영상으로 이어지지 않음 |
| 6 | 자막 | 소리 없이 보는 시청자를 놓침 |
| 7 | 공개 범위·예약 | 의도치 않은 즉시 공개 |
| 8 | 아동용 여부 | 잘못 설정 시 댓글·기능 제한 |

## 설명란 구조

설명란은 위에서부터 역할이 다릅니다.

```
[1행]   이 영상이 무엇인지 한 문장 — 목록에서 잘리기 전 구간
[공백]
[본문]  영상에서 다룬 내용 요약 (검색어가 자연스럽게 들어가게)
[챕터]  00:00 오프닝 / 01:20 첫 주제 / ...
[링크]  언급한 자료·이전 영상·재생목록
[고정]  채널 소개·구독 안내 (매 영상 동일)
```

**챕터는 반드시 `00:00`으로 시작**해야 인식됩니다. 시각은 오름차순이어야 하고, 구간이
너무 짧으면 표시되지 않습니다.

## 태그와 검색어

태그보다 **제목·설명에 자연스럽게 들어간 표현**이 더 크게 작용합니다. 태그를 채우려고
관련 없는 단어를 나열하지 않습니다 — 도움이 안 되고 정책 위반 소지가 있습니다.

## 재생목록

새 영상은 올리는 즉시 해당 시리즈 재생목록에 넣습니다. 재생목록은 **시리즈 = 재생목록**으로
1:1 대응시키고, 순서는 시청 순서(입문 → 심화)로 정렬합니다. 최신순 정렬은 시리즈에 부적합합니다.

## MCP 연동 (연결 시)

```
upload_video              영상 파일 업로드
  → update_video_metadata 제목·설명·태그·챕터
  → set_thumbnail         썸네일 적용
  → add_to_playlist       재생목록 배치
  → upload_caption        자막 등록
  → set_publish_schedule  공개 예약
```

MCP 미연결 상태에서는 같은 순서를 **유튜브 스튜디오에서 수동으로** 진행하도록 안내하고,
설명란·챕터 등 붙여넣을 텍스트를 완성해 드립니다. **올리지 않은 것을 올렸다고 말하지 않습니다.**

## 발행 직후 점검

발행하고 바로 확인합니다.

- 목록에서 썸네일과 제목이 의도대로 보이는가 (모바일 화면으로)
- 챕터가 실제로 표시되는가
- 재생목록에 들어갔는가
- 자막이 켜지는가

## 산출물

- 발행 체크리스트 (완료 여부 포함)
- 붙여넣을 설명란 전문 (첫 줄·본문·챕터·링크·고정 문구)
- 재생목록 배치안
- 예약 시각 (사용자 시간대 기준으로 명시)

## 주의

- 예약 시각은 **사용자의 시간대**로 적고, 설정 후 한 번 더 확인합니다.
- 저작권이 불확실한 음원이 들어간 영상은 발행 전에 알립니다 — 발행 후 수익 제한이 붙습니다.
- 아동용 설정은 잘못 고르면 댓글·알림이 막힙니다. 확신이 없으면 사용자에게 확인받습니다.
