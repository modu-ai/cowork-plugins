# 썸네일·제목 패키징 (youtube-thumbnail-title)

> `moai-youtuber` | 제목 + 썸네일을 한 세트로

## 개요

제목과 썸네일은 따로 만들면 반드시 어긋납니다. 같은 말을 두 번 하거나(정보 낭비), 서로 다른
이야기를 하거나(혼란) 둘 중 하나가 됩니다. 이 스킬은 둘을 **한 묶음(패키지)으로** 설계해서
겹치지 않고 이어지게 만듭니다.

## 트리거 키워드

썸네일, 제목, 타이틀, 클릭률, CTR, 패키징, 후크, 문구, 표지, 미리보기 이미지

## 핵심 원칙 — 역할 나누기

| 요소 | 맡는 역할 |
|---|---|
| 썸네일 | 눈에 걸리게 한다 — 상황·감정·대상을 한눈에 |
| 제목 | 궁금증을 완성한다 — 썸네일이 못 말한 것 |

**썸네일에 쓴 문구를 제목에 그대로 반복하지 않습니다.** 같은 말을 두 번 하면 정보량이 절반이
됩니다.

## 작업 흐름

### 1. 이 영상의 한 줄 약속 정하기

시청자가 이 영상을 보고 얻는 것을 한 문장으로 적습니다. 제목·썸네일은 전부 이 문장에서
파생됩니다. 이 문장이 흐리면 뒤 작업이 전부 흔들립니다.

### 2. 제목 후보

성격이 다른 방향으로 후보를 냅니다 — 비슷한 후보 여러 개는 선택에 도움이 안 됩니다.

| 방향 | 성격 |
|---|---|
| 결과형 | 무엇을 얻는지 앞세움 |
| 질문형 | 시청자의 의문을 그대로 |
| 대비형 | 통념과 반대되는 지점 |
| 구체형 | 상황·조건을 좁혀 대상을 특정 |

제목은 **앞쪽 절반이 승부처**입니다. 모바일 목록에서 뒤가 잘리기 때문에 핵심어를 앞에 둡니다.

### 3. 썸네일 구성안

이미지를 만들기 전에 **글로 먼저 확정**합니다.

| 항목 | 정할 것 |
|---|---|
| 문구 | 짧게. 화면에서 한눈에 읽히는 길이 |
| 주 피사체 | 얼굴인지 대상물인지 · 위치 |
| 표정·동작 | 영상 내용과 일치하는 것 |
| 색 | 배경과 문구의 대비 · 채널 색 규칙 |
| 여백 | 우측 하단은 재생 시간 표시에 가려짐 — 비워 둠 |

작은 화면에서 먼저 확인합니다. 축소했을 때 문구가 안 읽히면 실패한 썸네일입니다.

### 4. 겹침 점검

제목과 썸네일 문구를 나란히 놓고 확인합니다.

- 같은 단어가 반복되는가 → 하나를 바꿉니다
- 둘을 합쳐 읽었을 때 하나의 이야기가 되는가
- 내용에 없는 것을 약속하고 있지는 않은가

### 5. 이미지 생성 위임

확정된 구성안을 `moai-media`로 넘깁니다.

```
youtube-thumbnail-title (문구·구도·색·표정 확정)
  → moai-media:media-higgsfield-image (이미지 생성)
  → youtube-thumbnail-title (축소 확인 → 필요 시 문구·대비 조정)
  → youtube-publish-ops (set_thumbnail으로 적용)
```

## 산출물

- 이 영상의 한 줄 약속
- 성격이 다른 제목 후보들
- 썸네일 구성안 (문구·구도·표정·색·여백)
- 겹침 점검 결과
- moai-media 위임용 생성 요청문

## 주의

- **내용에 없는 것을 약속하지 않습니다.** 과장 썸네일은 클릭을 얻고 시청 지속을 잃습니다.
  결과적으로 채널에 손해입니다.
- 다른 사람의 얼굴·로고·상표를 썸네일에 쓰지 않습니다.
- 클릭률이 낮다는 판단은 실제 수치를 확인한 뒤에 합니다 — 느낌으로 바꾸지 않습니다.
  숫자 확인은 `youtube-analytics-review`에 넘깁니다.
