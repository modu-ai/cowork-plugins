# 촬영·편집 지시 (youtube-production)

> `moai-youtuber` | 촬영 준비 → 편집 지시서

## 개요

편집이 오래 걸리는 진짜 이유는 편집 실력이 아니라 **촬영 때 안 찍은 것**과 **지시가 없는 것**
입니다. 이 스킬은 촬영 전에 필요한 컷을 미리 확정하고, 편집 단계에서는 판단이 필요 없는
지시서를 만들어 작업 시간을 줄입니다.

## 트리거 키워드

촬영, 녹화, 편집, 편집 지시서, 컷 리스트, 자막, B롤, 인서트, 효과음, 조명, 마이크,
화면 녹화, 편집자, 외주

## 1단계 — 촬영 전 세팅 점검

| 구분 | 점검 항목 |
|---|---|
| 소리 | 마이크 거리와 입력 레벨 · 에어컨/냉장고 소음 · 이어폰 모니터링 |
| 빛 | 얼굴 정면 광원 · 창문 역광 여부 · 촬영 중 밝기 변화(해질녘) |
| 화면 | 해상도·프레임 고정 · 초점 · 배경 정리 · 개인정보 노출물 |
| 저장 | 저장 공간 잔량 · 배터리 · 자동 종료 설정 해제 |

**소리가 화면보다 중요합니다.** 흔들린 화면은 견디지만 잡음 섞인 소리는 이탈로 직결됩니다.

## 2단계 — 확보할 컷 목록

대본을 받아 **촬영 중에 반드시 찍어야 할 것**을 미리 뽑습니다. 이걸 안 하면 편집 단계에서
"화면이 비는" 구간이 생기고, 재촬영이 필요해집니다.

| 컷 종류 | 언제 필요한가 |
|---|---|
| 메인 토킹 | 대본 전 구간 |
| 인서트 | 말로만 설명하는 대상이 있을 때(제품·화면·자료) |
| 전환용 | 주제가 바뀌는 지점마다 |
| 여분 | 오프닝·엔딩 후보를 두 가지 이상 |

말하면서 손으로 가리키는 대상은 **반드시 그 대상을 따로 촬영**해 둡니다.

## 3단계 — 편집 지시서

편집자가 되묻지 않고 작업할 수 있는 수준으로 씁니다. 지시서의 각 줄은 **시각·동작·이유**를
담습니다.

```
[00:00-00:08]  오프닝
  컷    : 인사 구간 유지, 앞의 헛기침 잘라내기
  자막  : 영상 제목을 화면 상단에 표시
  이유  : 첫 화면에서 무슨 영상인지 즉시 알리기

[00:08-00:35]  문제 제기
  컷    : 말 사이 공백 0.3초 이상은 잘라 붙이기
  B롤   : "이런 상황" 언급 구간에 인서트 삽입
  자막  : 핵심 문장만 강조 자막
  효과음: 없음 (초반 과한 효과음은 이탈 유발)
```

### 자막 원칙

- 전체 자막을 넣을지, 강조 자막만 넣을지 **먼저 정합니다.** 섞이면 지저분해집니다.
- 한 화면에 두 줄을 넘기지 않습니다.
- 숫자·고유명사·외래어는 자막으로 반드시 보강합니다(듣고 놓치기 쉬운 정보).

### 컷 편집 원칙

- 말 사이 공백을 줄이는 것이 가장 큰 체감 개선입니다.
- 화면 전환 효과는 주제가 바뀌는 지점에만 씁니다. 문장마다 넣으면 피로합니다.
- 오프닝은 짧게. 채널 로고 애니메이션을 앞에 길게 두면 초반 이탈이 커집니다.

## B롤·인서트 조달

직접 촬영하지 못한 인서트는 `moai-media`에 위임합니다.

```
youtube-production (필요한 인서트 목록 확정 — 무엇을·몇 초·어떤 분위기)
  → moai-media:media-higgsfield-video 또는 media-higgsfield-image (실제 생성)
  → youtube-production (편집 지시서에 배치)
```

효과음·내레이션이 필요하면 `moai-media:media-audio-gen`으로 넘깁니다.

## 산출물

- 촬영 전 세팅 점검표
- 확보할 컷 목록 (대본 구간별)
- 편집 지시서 (시각·컷·자막·B롤·효과음)
- 외부 조달이 필요한 인서트 목록 (moai-media 위임용)

## 주의

- 남의 영상 클립·음원·이미지를 인서트로 쓰자고 제안하지 않습니다. 출처가 확실한 소재만 씁니다.
- 지시서에 "적당히", "느낌 있게" 같은 말을 쓰지 않습니다 — 편집자가 되묻게 됩니다.
- 편집 시간을 예측해 달라는 요청에는 구간 수와 작업 종류로 답하고, 소요 일수는 말하지 않습니다.
