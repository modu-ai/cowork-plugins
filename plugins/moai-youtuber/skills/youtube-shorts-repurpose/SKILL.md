# 쇼츠 리퍼포징 (youtube-shorts-repurpose)

> `moai-youtuber` | 롱폼 · 라이브 → 쇼츠

## 개요

가장 저렴한 콘텐츠는 **이미 만든 것**입니다. 한 시간짜리 라이브에는 보통 여러 개의 쇼츠 소재가
들어 있는데, 대부분 그냥 묻힙니다. 이 스킬은 잘라 쓸 구간을 찾아내고, 세로 화면에 맞게
재구성하는 지시서를 만듭니다.

## 트리거 키워드

쇼츠, Shorts, 숏폼, 하이라이트, 클립, 리퍼포징, 세로 영상, 재활용, 다시보기 편집

## 1단계 — 뽑을 구간 찾기

쇼츠로 살아남는 구간에는 공통점이 있습니다.

| 특징 | 설명 |
|---|---|
| 앞뒤 설명 없이 이해됨 | 맥락을 몰라도 그 자체로 완결 |
| 하나의 이야기 | 주제가 하나. 두 가지를 담으면 둘 다 죽음 |
| 시작 지점이 강함 | 첫 순간에 상황이 파악됨 |
| 감정 또는 정보의 밀도 | 놀람·공감·정확한 팁 중 하나 |

**설명을 덧붙여야 이해되는 구간은 쇼츠에 부적합합니다.** 그런 구간은 원본 영상 링크를 거는
편이 낫습니다.

라이브 다시보기라면 `youtube-live-ops`가 남긴 하이라이트 표시를, 없으면 챕터와 채팅 반응이
몰린 구간을 후보로 삼습니다.

## 2단계 — 세로 화면 재구성

가로 영상을 세로로 옮기면 화면의 상당 부분이 잘립니다. 무엇을 남길지 정해야 합니다.

| 원본 화면 | 세로 전환 방법 |
|---|---|
| 말하는 사람 하나 | 얼굴 중심으로 잘라내기 |
| 화면 공유·자료 | 위쪽에 자료, 아래쪽에 얼굴 (위아래 분할) |
| 두 사람 대화 | 말하는 쪽으로 그때그때 이동 |
| 넓은 장면 | 핵심 대상만 확대 — 안 되면 이 구간은 포기 |

## 3단계 — 시작 다듬기

쇼츠는 **첫 순간에 결정**됩니다.

- 인사·서론을 전부 잘라내고 **본론 한복판에서 시작**합니다.
- 첫 화면에 상황을 알려 주는 자막을 답니다(소리 없이 보는 시청자가 많습니다).
- 원본의 "그래서 아까 말씀드린" 같은 연결어는 잘라내거나 자막으로 대체합니다.

## 4단계 — 자막

쇼츠는 자막이 사실상 필수입니다.

- 화면 중앙보다 약간 위에 배치합니다 — 하단은 제목·계정 정보에 가려집니다.
- 한 번에 한두 줄. 말 속도에 맞춰 끊습니다.
- 원본 발화를 그대로 옮기되, 군더더기(음··· 어···)는 뺍니다.

## 5단계 — 쇼츠 제목과 원본 연결

- 제목은 롱폼보다 더 짧게. 궁금증 하나만 담습니다.
- 설명란 첫 줄에 **원본 영상 링크**를 넣습니다. 쇼츠의 목적 중 하나는 롱폼으로 데려오는 것입니다.
- 원본 영상 설명란에도 파생된 쇼츠를 연결해 두면 서로 순환합니다.

## 체인 연결

```
youtube-live-ops 또는 youtube-production (원본 + 하이라이트 표시)
  → youtube-shorts-repurpose (구간 선별 · 세로 재구성 지시)
  → moai-media (필요 시 인서트·효과음 생성)
  → youtube-publish-ops (발행 · 원본 상호 연결)
  → moai-marketer:content-sns-content (다른 채널로 확산이 필요할 때)
```

## 산출물

- 뽑을 구간 목록 (시작·끝 시각, 선정 이유)
- 구간별 세로 전환 지시 (무엇을 남기고 무엇을 자를지)
- 시작 자막 문구
- 전체 자막 원고
- 쇼츠 제목 후보와 설명란 (원본 링크 포함)

## 주의

- 원본에 들어간 음원·클립의 저작권은 쇼츠에도 그대로 따라옵니다. 원본에서 문제가 없었더라도
  잘라 쓸 때 다시 확인합니다.
- 맥락을 잘라내 **원래 의미와 달라지는 편집**을 하지 않습니다. 특히 대담·인터뷰 구간에서
  위험합니다.
- 구간 시각은 원본 영상 기준으로 정확히 적습니다 — 어림값을 쓰면 편집 단계에서 다시 찾아야 합니다.
