# Threads 규격 사양 (2026 기준)

## 텍스트 제한

| 항목 | 규격 |
|------|------|
| 최대 길이 | 500 UTF-8 바이트 |
| 바이트 계산 | ASCII 1B, 한글 3B, 이모지 4B (국기 깃발 8B) |
| 초과 시 | HTTP 400 에러 |

## 바이트 계산 상세

```
ASCII (영문, 숫자, 공백, 일반 기호): 1바이트
  예: "Hello!" = 6바이트

한글 (가-힣): 3바이트
  예: "안녕하세요!" = 16바이트 (한글 5×3 + ! = 16)

이모지 (대부분): 4바이트
  예: "😀" = 4바이트

국기 깃발 이모지 (🇰🇷, 🇺🇸): 8바이트
  예: "🇰🇷" = 8바이트 (regional indicator 2개)
```

## 토픽 태그 (Topic Tags)

| 항목 | 규격 |
|------|------|
| 최대 개수 | 1개 권장 (알고리즘) |
| 형식 | `#태그이름` |
| 위치 | 본문 어디든 가능 |

## 링크 (Links)

| 항목 | 규격 |
|------|------|
| 최대 개수 | 5개 |
| 프리뷰 | 자동 생성 |
| 형식 | 일반 URL |

## 이미지/비디오 (이 스킬 범위 외)

| 항목 | 규격 |
|------|------|
| 이미지 | 최대 10장, JPEG/PNG ≤ 8MB |
| 비디오 | MOV/MP4 ≤ 1GB, ≤ 5분 |

이미지/비디오 포스트는 `threads-publish-image`, `threads-publish-video` 도구를 직접 호출하세요.
