# 문체 프로필 템플릿 (style-profile-template)

> 이 파일은 `threads-style-learn` 스킬이 문체 분석 결과를 채우는 **양식** 이다.
> 사용자마다 값이 다르다 — 예시값(`<...>`) 을 분석 결과로 바꿔 `threads_style_save` 로 저장하라.
> 저장된 프로필은 `threads-post-draft` 가 초안 작성 시 자동으로 불러와 적용한다.

## 작성 원칙

1. **근거 기반**: 모든 판단은 수집된 포스팅에서 *관찰된* 사실에 기반한다. 숫자(%·횟수·평균) 로 표현할 수 있으면 숫자로.
2. **추측 금지**: 샘플로 판단할 수 없는 차원은 "관찰되지 않음" 이라고 솔직히 쓴다.
3. **간결하게**: 각 항목 1-2줄. 긴 산문이 아니라 초안 작성 시 *즉시 참조 가능한* 메모 형태.

---

## <사용자명> 문체 프로필

**분석 일자**: <YYYY-MM-DD>
**샘플 수**: <N>개 포스팅 (Threads / Facebook / 블로그 등)

### 1. 말투 (톤)

- 주 체(해요체 / 하십시오체 / 해체 / 혼합): <...>
- 비율(혼합인 경우): <예: 해요체 80% / 해체 20%>
- 존댓말·반말 전환 패턴: <예: 본문은 해요체, 제목은 명사구>

### 2. 문장 길이

- 평균 문장 길이(글자 수): <예: 15자>
- 가장 짧은 문장: <예: 3자 ("맞습니다.")>
- 가장 긴 문장: <예: 40자>
- 패턴: <예: 짧게 끊어 쓴다 / 긴 복문을 쓴다>

### 3. 단락 리듬

- 평균 단락 문장 수: <예: 1-2문장 (줄바꿈 자주)>
- 줄바꿈 습관: <예: 문장 단위로 줄바꿈 / 생각 단위로 묶음>
- 리스트/번호 사용: <예: 자주 쓴다 / 거의 안 쓴다>

### 4. 이모지 빈도·스타일

- 포스팅당 평균 이모지 수: <예: 2개>
- 주로 쓰는 이모지: <예: ✨, 🙏, 💡>
- 위치: <예: 문장 끝 / 제목 / 본문 중간>
- 안 쓰는 경우: <예: 거의 안 씀>

### 5. 오프닝 훅 (첫 문장 패턴)

- 주 패턴: <예: 질문으로 시작 (7/10) / 사실 선언 (3/10)>
- 예시:
  - "<포스팅1 첫 문장>"
  - "<포스팅2 첫 문장>"

### 6. 클로징 패턴 (마무리)

- 주 패턴: <예: 독자에게 질문 / 행동 유도 / 인사 / 여운>
- 예시:
  - "<포스팅1 마지막 문장>"
  - "<포스팅2 마지막 문장>"

### 7. 해시태그 / 토픽 태그 습관

- 사용 여부: <예: 쓴다 / 안 쓴다>
- 개수: <예: 포스팅당 0-1개>
- 종류: <예: 주제 태그 / 브랜드 태그>

### 8. 유머 / 위트 수준

- 수준: <예: 거의 없음 / 가끔 / 적극적>
- 스타일: <예: 말장난·드립 / 상황 극화 / 언어유희>

### 9. 시그니처 구절 (반복 표현)

- 정어구·말버릇: <예: "~ 어떻게 생각하세요?", "사실,", "진짜로">
- 반복되는 마무리 표현: <예: "~봅시다", "~길 바랍니다">

### 10. 어휘 레벨

- 전문 용어 사용: <예: 거의 안 씀 / 업계 용어 자주>
- 일상어 비중: <예: 높음 / 보통>
- 외래어·영어 혼용: <예: 가끔 / 자주 / 안 씀>

### 11. 띄어쓰기 / 맞춤법

- 엄격도: <예: 엄격 / 다소 느슨>
- 특이 패턴: <예: 의도적 줄임말 ("이렇게" → "이렇께" X — 실제 관찰되는지만 기록)>

## 초안 작성 시 적용 가이드 (threads-post-draft 용)

위 프로필을 바탕으로 초안을 쓸 때:

1. **말투**: <주 체> 로 쓴다. <혼합 비율> 유지.
2. **문장 길이**: 평균 <N>자 내외로, <짧게/길게>.
3. **오프닝**: <주 패턴> 으로 시작.
4. **클로징**: <주 패턴> 으로 마무리.
5. **이모지**: 포스팅당 <N>개 내외, <주 이모지> 활용.
6. **시그니처 구절**: <반복 표현> 을 자연스럽게 녹인다.
7. **해시태그**: <사용 여부·개수> 반영.

> 주의: 이 프로필은 *참조* 이다. 기계적으로 복붙하지 말고, 주제에 맞게 자연스럽게 구현할 것.
