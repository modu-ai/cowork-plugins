# Threads 문체 학습 (threads-style-learn)

## 개요

과거 Facebook/Threads 포스팅 3-10개를 받아 **문체(style profile)** 를 분석하고, 안정적인 경로에 저장합니다. 저장된 프로필은 `threads-post-draft` 스킬이 초안 작성 시 자동으로 불러와 적용합니다.

> **왜 필요한가**: 같은 내용이어도 "내 글투" 로 쓰인 글이 훨씬 자연스럽게 다가갑니다. 이 스킬은 일회성 분석이 아니라 — 한 번 저장하면 이후 *모든* 초안 작성에 재사용되는 영구 프로필을 만듭니다.

## 트리거 키워드

문체, 스타일, 학습, 분석, 글투, 톤앤매너, 톤, 말투, 프로필, 저장, 과거 포스팅, 이전 글

## 워크플로우

### 1단계: 과거 포스팅 수집 (3-10개)

사용자에게 과거 Facebook/Threads 포스팅을 붙여넣어 달라고 요청합니다. 최소 3개, 권장 5-10개가 있어야 문체가 안정적으로 잡힙니다.

요청 예시:
```markdown
문체를 분석하려면 과거에 직접 쓰신 포스팅 3-10개를 붙여넣어 주세요.
- Threads, Facebook, 블로그 어디든 상관없습니다
- *직접 쓰신 글* 이어야 합니다 (공유/인용글 X)
- 짧은 글·긴 글 섞여 있을수록 더 좋습니다
- 파일 경로를 알려주셔도 됩니다 (예: `~/posts.txt`)
```

또는 사용자가 파일 경로를 알려주면 Read 도구로 읽어옵니다.

### 2단계: 문체 차원 분석

수집된 포스팅에서 아래 차원들을 추출합니다. 각 차원은 `references/style-profile-template.md` 의 항목과 1:1 로 대응합니다.

| 차원 | 분석 포인트 |
|------|------------|
| **말투(톤)** | 경어체(해요체/하십시오체) · 반말(해체) · 혼합. 비율(%) 로 기록 |
| **문장 길이** | 평균 글자 수, 가장 긴/짧은 문장. 짧고 끊어 쓰는지 길게 쓰는지 |
| **단락 리듬** | 한 문단에 몇 문장? 줄바꿈을 자주 하는지. 리스트/번호 자주 쓰는지 |
| **이모지 빈도·스타일** | 포스팅당 평균 이모지 수. 잘 쓰지 않는지 / 풍부하게 / 특정 이모지 반복 |
| **오프닝 훅** | 첫 문장 패턴 (질문 · 인사 · 선언 · 사실 인용). "자주 시작하는 방식" |
| **클로징 패턴** | 마무리 패턴 (질문 던지기 · 행동 유도 · 여운 남기기 · 인사) |
| **해시태그/토픽태그 습관** | 쓰는지 안 쓰는지. 쓰면 몇 개, 어떤 종류 |
| **유머/위트 수준** | 거의 없음 / 가끔 / 적극적. 말장난·드립 스타일 |
| **시그니처 구절** | 반복되는 표현·정어구 (예: "~입니다", "~봅시다", 특정 이모티콘) |
| **어휘 레벨** | 전문 용어 자주 쓰는지 / 일상어 위주인지 |
| **띄어쓰기/맞춤법** | 엄격한지 / 여느 정도 느슨한지 |

분석은 추측이 아니라 **수집된 글에서 실제로 관찰된 증거** 에 기반해야 합니다. 예시:
- 좋음: "10개 중 8개가 해요체, 문장 평균 15자로 짧게 끊어 씀"
- 나쁨: "아마 친근한 톤일 것 같습니다" (근거 없음)

### 3단계: 프로필 작성 → 저장

분석 결과를 `references/style-profile-template.md` 양식으로 채워 마크다운을 만듭니다. 그리고 `threads_style_save` 도구로 저장합니다:

```python
threads_style_save(
    profile_markdown="""# <사용자명> 문체 프로필

## 말투 (톤)
- 해요체 80% / 해체 20% 혼합
- ...

## 시그니처 구절
- "~ 어떻게 생각하세요?" (질문으로 마무리)
...
""",
    path=None  # 기본 경로: $CLAUDE_PLUGIN_ROOT/mcp-servers/moai-threads-poster/.data/style-profile.md
)
```

- `path=None` 이면 기본 경로(`.data/style-profile.md`) 에 저장됩니다 — 한 번 저장하면 이후 `threads-post-draft` 가 자동으로 불러옵니다.
- 다른 경로에 저장하려면 `path=` 로 지정 (권장하지 않음 — 기본 경로가 자동 적용 대상).

### 4단계: 저장 확인 + 다음 단계 안내

저장 결과(`{path, saved: True, chars: N}`) 를 사용자에게 알려주고, 다음을 안내합니다:
- 프로필이 저장되었으니 이제 `threads-post-draft` 로 초안을 작성하면 자동으로 이 문체가 적용됩니다.
- 프로필을 다시 분석/갱신하려면 이 스킬을 다시 호출 (덮어쓰기).

## 출력 형식

```markdown
## 문체 프로필 저장 완료

**분석 샘플**: N개 포스팅
**저장 경로**: <path>
**분석 차원**: 11개 (말투·문장 길이·단락 리듬·이모지·오프닝·클로징·해시태그·유머·시그니처·어휘·띄어쓰기)

### 핵심 특징 (요약)
- 말투: 해요체 중심 (80%)
- 문장: 평균 15자, 짧게 끊어 씀
- 오프닝: 질문으로 시작 (7/10)
- 클로징: 독자에게 질문 던지기 (8/10)
- 이모지: 포스팅당 평균 2개
- 시그니처: "~ 어떻게 생각하세요?"

**다음 단계**: 이제 `threads-post-draft` 로 초안을 작성하면 저장된 문체가 자동 적용됩니다. 프로필 갱신은 이 스킬을 다시 호출하면 덮어쓰기됩니다.
```

## 주의사항

| 상황 | 대응 |
|------|------|
| 샘플이 3개 미만 | "최소 3개는 필요합니다" 안내, 더 붙여넣어 달라고 요청 |
| 샘플이 직접 쓴 글이 아닐 때 (인용/공유) | "직접 쓰신 글로 다시 주시면 정확합니다" 안내 |
| 차원이 모호할 때 (예: 유머 수준 판단 안 됨) | "이 샘플만으로는 판단 어렵습니다 — '관찰되지 않음' 으로 기록" (추측 금지) |
| 분석이 주관적일 때 | 가능한 한 숫자(%·횟수·평균) 로 근거 제시 |
| 다시 분석 요청 | 기존 프로필을 덮어쓴다고 안내 후 재진행 |

## 관련 스킬

| 스킬 | 사용 시점 |
|------|----------|
| `threads-post-draft` | 저장된 프로필을 적용해 초안 작성·즉시 발행 |
| `threads-multichannel` | 작성된 초안을 Threads/Facebook/X 용으로 포맷 |

## 이 스킬을 사용하지 말아야 할 때

- 초안 작성·발행: `threads-post-draft` 스킬 사용 (이 스킨은 프로필 저장까지)
- 멀티 채널 포맷(Facebook/X): `threads-multichannel` 스킬 사용
- 프로필 없이 한 번만 글 쓰기: `threads-post-draft` 가 프로필 없을 때 기본 톤으로 작성하므로 이 스킬은 생략 가능

## 저장 경로·자격증명

- **저장 경로(기본)**: `$CLAUDE_PLUGIN_ROOT/mcp-servers/moai-threads-poster/.data/style-profile.md` (`.data/` 는 gitignored — 개인 문체가 저장소에 올라가지 않습니다).
- **자격증명 불필요**: 이 스킬의 저장 도구(`threads_style_save`/`threads_style_load`)는 Threads API 자격증명 없이 동작합니다 — 로컬 파일 I/O 전용입니다.
- **발행 전 설정**(Threads 자격증명)은 초안 *발행* 시에만 필요 — `threads-post-draft` 의 "발행 전 설정" 섹션 참조.
