# 브랜드 참고 자료 — 사용 경계 고지

> `systems/` 디렉터리는 저장소 루트 [LICENSE](../../../../LICENSE)(Apache-2.0)의
> **적용 범위에서 제외**됩니다. 자세한 내용은 루트 [NOTICE](../../../../NOTICE) §3.

## 무엇인가

`systems/*.md` 는 제3자 브랜드가 웹·앱에 **공개한 디자인 표현을 관찰·분석한 참고
자료**입니다. 색 토큰, 타이포 스케일, 여백 그리드, 컴포넌트 관찰 결과를 담고 있습니다.

## 권리 관계

| 대상 | 권리 |
|---|---|
| 분석 서술·정리 구조 | modu-ai (단, 아래 제한 적용) |
| 색·치수 등 수치 | 사실 정보 — 저작권 대상 아님 |
| **각 브랜드의 디자인·상표·로고** | **해당 브랜드 소유자** |
| **지정된 서체** | **각 파운드리** — 사용에 별도 라이선스 필요 |

modu-ai는 이 브랜드들과 제휴·후원·보증 관계가 **없으며**, 각 브랜드의 권리에 대해
어떠한 허락도 부여할 수 없습니다. Apache-2.0이 부여하는 자유는 **modu-ai가 가진 권리의
범위 안에서만** 유효합니다.

## 하지 말아야 할 것

- 특정 브랜드의 시각적 정체성을 그대로 입힌 산출물을 **상업적으로 배포**하는 것
  (트레이드드레스 침해·부정경쟁 소지)
- 해당 브랜드가 후원·제휴한 것처럼 보이게 하는 것
- 지정된 유료 서체(`Helvetica Now`, `Futura ND`, `SF Pro`, `Univers`, `Söhne`,
  `GT Walsheim`, `Tiempos`, `Circular`, `Proxima Nova`, `Gotham` 등)를
  **라이선스 없이 산출물에 임베드·로드**하는 것

## 권장 사용법

이 자료는 **"좋은 디자인 시스템은 어떻게 구성되는가"를 배우고, 자기 브랜드의 토큰을
설계할 때 참고**하는 용도로 쓰세요. 색·서체·간격을 그대로 복사하지 말고, 구조(스케일
단계 수, 대비 전략, 컴포넌트 분해 방식)를 참고하는 것이 안전하고 결과도 낫습니다.

서체는 오픈 라이선스 대체재로 바꿔 쓰시길 권합니다.

| 원본 (유료) | 오픈 라이선스 대체 |
|---|---|
| Helvetica Now / Neue Haas Grotesk | Inter, Public Sans |
| Futura | Jost, Poppins |
| SF Pro | Inter, Manrope |
| Univers / Proxima Nova / Circular | Inter, Figtree, Manrope |
| Söhne / GT Walsheim | Inter, Outfit |
| Tiempos / GT Sectra | Source Serif 4, Noto Serif |
| Gotham | Montserrat, Archivo |
| 한국어 전반 | Pretendard (OFL) |
