# quality-gate.md — 출시 전 기계 점검

> `design-landing-motion` | 4단계. 통과하지 못하면 끝난 게 아니다.
> 취향 논쟁이 아니라 **예/아니오로 답할 수 있는 항목**만 담는다.

**Evidence tier:** 2차 (Higgsfield 공식 스킬 `higgsfield-websites` v0.12.0, MIT — `review-rubric.md`·`design-recipe.md` 착안) + 웹 표준 접근성·성능 통념

---

## A. 초기 렌더 (가장 자주 걸리는 곳)

- [ ] JS를 끈 상태에서 히어로가 **완성된 모습**으로 보인다 (빈 화면·첫 프레임만 아님)
- [ ] 스크럽을 쓴다면 프레임 1이 정지 이미지로 렌더돼 있다
- [ ] 레이어 효과라면 합성된 상태가 기본값이다
- [ ] 마스크 리빌이라면 마스크 해제 상태가 초기 렌더에 포함된다

**점검법:** 브라우저에서 JS를 끄고 첫 화면을 캡처한다. 혹은 헤드리스로 스크립트 실행 전 스크린샷을 찍는다.

---

## B. 저감모션

- [ ] `prefers-reduced-motion: reduce`에서 핀·스크럽·무한 루프가 **동작하지 않는다**
- [ ] 그 상태에서 보이는 것은 **완성된 최종 상태**다
- [ ] CSS 전역 차단뿐 아니라 **JS에서도** 초기화를 건너뛴다
- [ ] 캔버스·WebGL은 아예 생성되지 않거나 정적 이미지로 대체된다

**점검법:** OS 설정에서 동작 줄이기를 켜고 다시 본다. 또는 개발자도구에서 해당 미디어 기능을 강제한다.

---

## C. 모바일

- [ ] 커서 기반 효과에 **스크롤 대응 대체**가 있다
- [ ] 긴 핀 구간이 모바일에서 짧아진다
- [ ] 가로 스크롤이 생기지 않는다
- [ ] 터치 스크롤이 가로채이지 않는다
- [ ] 열화 내용이 문서·보고에 **명시**돼 있다

"데스크톱만 됨"은 열화가 아니라 방치다.

---

## D. 성능

- [ ] 핫패스에서 `transform`·`opacity` 외의 속성을 애니메이션하지 않는다
- [ ] 히어로 이미지가 2K 이하이고 적절히 압축돼 있다
- [ ] WebGL을 쓴다면 DPR 상한이 걸려 있다
- [ ] WebGL을 쓴다면 화면 밖에서 렌더 루프가 멈춘다
- [ ] 라우트 이동·언마운트에서 three 리소스가 해제된다
- [ ] 사용하지 않는 무거운 의존성이 번들에 남아 있지 않다

---

## E. 접근성

- [ ] 모든 버튼 라벨이 **자기 배경 대비** WCAG AA를 넘는다 (사진 위 고스트 버튼 포함)
- [ ] 본문 텍스트 대비가 AA를 넘는다 — 움직이는 배경 위라면 **가장 불리한 프레임 기준**으로
- [ ] 키보드 포커스가 핀 구간에 갇히지 않는다
- [ ] 포커스 링이 보인다 (`outline: none`만 걸고 대체를 안 준 곳이 없다)
- [ ] DOM 순서가 시각 순서와 일치한다
- [ ] 의미 있는 이미지에 대체 텍스트가 있고, 장식 이미지는 비워져 있다

---

## F. 에셋

- [ ] stock·picsum·로렘 이미지가 **하나도 없다**
- [ ] CSS 그라디언트로 이미지를 대신한 곳이 없다
- [ ] 내려받은 모든 파일이 실제로 어딘가에서 참조된다
- [ ] 채택되지 않은 후보가 공개 디렉터리에 남아 있지 않다
- [ ] 이미지가 동일 출처에서 제공된다 (외부 CDN 직링크 없음)
- [ ] OG 이미지가 1200×630이고 `<head>`에 연결돼 있다
- [ ] 파비콘 세트가 존재한다
- [ ] 아이콘이 한 세트로 통일돼 있다 (한 시각 영역에 두 세트 혼용 없음)
- [ ] 이미지 안에 본문 텍스트가 구워져 있지 않다

---

## G. 카피

- [ ] 같은 의도의 CTA가 페이지 전체에서 **한 표현**으로 통일돼 있다
- [ ] 지어낸 성과 수치가 없다 (목업 표기가 없는 한)
- [ ] 가짜 후기 이름·워터마크 stock 얼굴이 없다
- [ ] 채움 동사(혁신적인·차세대·seamless·unleash)가 없다
- [ ] "스크롤해서 더 보기" 류 안내 문구가 없다
- [ ] 헤드라인 8단어 이하, 부연 25단어 이하
- [ ] 화면의 모든 문자열을 다시 읽었고 어색한 곳을 고쳤다

---

## H. 브랜드 정합

- [ ] 팔레트를 벗어난 색이 눈에 띄지 않는다
- [ ] 형태 언어(각/둥근)가 디자인 시스템과 맞다
- [ ] 참조한 디자인 시스템 파일 경로가 보고에 적혀 있다 (없으면 "근거 없음"이 적혀 있다)
- [ ] 생성 에셋의 그레이딩이 서로 어긋나지 않는다 (한 번에 모아 확인했다)

---

## I. 구조

- [ ] 시그니처 효과가 **하나**다
- [ ] 그 효과와 컨셉 스파인의 연결이 한 문장으로 적혀 있다
- [ ] 같은 세션 직전 빌드와 6축 중 4축 이상 다르다 (해당 시)

---

## 실패 처리

걸린 항목이 있으면 **고치거나, 못 고치면 보고에 명시**한다. 조용히 넘기지 않는다.

특히 아래 셋은 넘기면 안 된다 — 사용자가 나중에 발견하면 신뢰를 잃는 종류다:

1. **초기 렌더가 비어 있음** (A) — 공유 카드·검색엔진·JS 실패 시 전부 빈 페이지
2. **저감모션 대체 없음** (B) — 접근성 요구사항이고, 어지럼증을 유발할 수 있다
3. **stock 이미지 잔존** (F) — 비용을 들여 만든 이유가 사라진다

모션을 제대로 끝낼 수 없다면 **정적 페이지로 내는 것이 정답**이다. 반쯤 붙은 스크롤 효과보다 낫다.
