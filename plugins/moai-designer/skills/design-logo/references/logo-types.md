# logo-types.md — 로고 타입 7종 분류와 선택 가이드

> `design-logo` 참조 파일. 로고 타입을 고를 때 연다.
> 출처: Vistaprint "7 Types of Logos and When to Use Them" (https://www.vistaprint.com/hub/types-of-logos)

## 7종 분류

| 타입 | 정의 | 브랜드 예시 |
|---|---|---|
| **워드마크** (Logotype) | 폰트 기반, 회사명 전체를 사용 | Visa, Coca-Cola, Google |
| **레터마크** (Monogram) | 이니셜/약자 사용 | IBM, CNN, HBO, NASA |
| **심볼** (Pictorial / Brand Mark) | 인식 가능한 그림, 텍스트 없음 | Apple, Target, Twitter/X |
| **애브스트랙트 마크** | 기하학적 형태, 문자 그대로가 아님 | BP, Pepsi, Adidas |
| **마스코트** | 의인화된 캐릭터 | KFC, Planters |
| **콤비네이션 마크** | 워드마크/레터마크 + 심볼/마스코트 | Burger King, Lacoste |
| **엠블럼** | 심볼 안에 텍스트 (배지/인장/크레스트) | Starbucks, Harley-Davidson, Harvard |

## 어떤 타입을 고를까

- 이름이 짧·읽기 쉽다 → **워드마크**. 커스텀 폰트로 브랜드 essence를 담는다.
- 이름이 길거나 작은 인쇄면에 쓰인다 → **레터마크**. 깔끔한 산세리프 또는 균형 잡힌 세리프.
- 언어 장벽 없이 글로벌하게 → **심볼**. 단순성이 핵심, 제한된 색 팔레트.
- 특정 제품에 얽매이지 않으려면 → **애브스트랙트**. 색이 의미를 담당하므로 브랜드 personality와 정렬.
- 가족/아동/로컬 친밀감 → **마스코트**. 따뜻하고 표현력 있는 색, 친근한 폰트.
- 다용도 시스템이 필요하면 → **콤비네이션**. 심볼 옆에서도 텍스트가 읽히도록 강한 대비.
- 전통/신뢰/공식 느낌 → **엠블럼**. 작은 크기에서도 읽히게 타이포를 단순하게, 얇은 선은 피한다(인쇄/자수에서 사라짐).

## AI(recraft_v4_1) 생성에서의 타입별 난이도

아래는 검증 출처들의 사실을 조합한 추론이다.

- **워드마크/레터마크** — Recraft는 텍스트 렌더링을 강점으로 홍보하지만, 철자 오류는 여전히 모니터링 필수. R3(따옴표+폰트)를 반드시 적용.
- **심볼/애브스트랙트** — AI가 가장 잘 다루는 영역. 텍스트가 없어 렌더링 실패 리스크가 낮다.
- **마스코트** — 캐릭터 일관성 유지가 과제. 여러 번 리롤하며 일관된 캐릭터를 잡아야 한다.
- **콤비네이션/엠블럼** — 텍스트+이미지 결합에서 가장 깨지기 쉽다. AI 생성 후 수동 수정이 거의 필수다.
