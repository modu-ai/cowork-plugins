# 3d.md — 3D 메시 생성·리깅·애니메이션

> `media-higgsfield-assets` | 이미지·텍스트에서 GLB 메시를 만들고, 리깅·애니메이션을 얹는 경로.
> 아래 값은 저술 시점 라이브 스냅샷이다. 호출 직전 `models_explore(action:'get')`으로 재확인한다.

**Evidence tier:** 1차 (라이브 `models_explore(action:'list', type:'3d')` 관측)

---

## 1. 입력 형태로 모델 고르기

| 가진 것 | 후보 | 비고 |
|---|---|---|
| 사물 사진 1장 | `sam_3_3d` (Meta) · `image_to_3d` (Meshy) | SAM은 객체를 검출해 분리, Meshy는 옵션이 풍부 |
| 같은 사물 여러 각도 1~4장 | `multi_image_to_3d` (Meshy) | **각도가 많을수록 형상 정확도가 올라간다** — 가능하면 이 경로 |
| 사람 전신 사진 1장 | `sam_3_3d_body` (Meta) | 인체 형상·포즈 복원 |
| 텍스트만 | `tripo_3d` | 참조 이미지 없이 생성 |
| 이미 있는 GLB URL | `3d_rigging` (Meshy) | 생성이 아니라 리깅만 |

`meshy_image_to_3d` / `meshy_multi_image_to_3d` / `meshy_rigging`은 각각 `image_to_3d` / `multi_image_to_3d` / `3d_rigging`과 동일 계약의 별칭으로 관측된다. 어느 id가 유효한지는 라이브 조회로 확인한다.

---

## 2. Meshy 계열 파라미터와 의존 관계

의존 관계를 어기면 오류다. 이 표가 이 파일의 핵심이다.

| 파라미터 | 기본 | 요구 조건 |
|---|---|---|
| `should_texture` | `false` | — (텍스처 계열의 전제) |
| `texture_prompt` | — | **`should_texture: true` 필요** |
| `texture_image_url` | — | **`should_texture: true` 필요** |
| `enable_pbr` | — | **`should_texture: true` 필요** |
| `enable_rigging` | `false` | — (애니메이션의 전제) |
| `enable_animation` | `false` | **`enable_rigging: true` 필요** |
| `animation_action_id` | — | **`enable_animation: true`일 때 필수** |
| `rigging_height_meters` | `1.7` | `enable_rigging: true`일 때만 사용 |
| `pose_mode` | — | `a-pose` / `t-pose`. 리깅 시 권장 |
| `target_polycount` | `30000` | 100 ~ 300000 |
| `topology` | `triangle` | `quad`(부드럽고 편집 쉬움) / `triangle`(디테일) |
| `should_remesh` | `true` | `false`면 `topology`·`target_polycount` 무시 |
| `symmetry_mode` | `auto` | `off` / `auto` / `on` |

**비용 주의:** `should_texture`·`enable_rigging`·`enable_animation`은 각각 비용을 더한다. 옵션을 켠 상태로 `get_cost` 프리플라이트를 돌린다.

**리깅 한계:** 인간형(humanoid) 스켈레톤 기준이다. 동물·사물은 결과가 나쁠 수 있으며, 리깅을 켜기 전에 그 사실을 사용자에게 알린다.

## 3. 애니메이션 클립 id

`animation_action_id`는 0~696 범위의 정수다. 전체 678종은 전용 애니메이션 조회 도구로 이름·카테고리 검색이 가능하다. 자주 쓰는 값:

| 동작 | id | 이름 |
|---|---|---|
| 대기 | 0 | idle |
| 걷기 | 30 | Casual_Walk |
| 달리기 | 16 | RunFast |
| 점프 | 466 | Regular_Jump |
| 손 흔들기 | 28 | Big_Wave_Hello |
| 춤 | 64 | All_Night_Dance |

이 6개 밖의 동작이 필요하면 값을 추측하지 말고 애니메이션 조회 도구로 검색한다.

## 4. SAM 계열 파라미터

| 파라미터 | 기본 | 뜻 |
|---|---|---|
| `detection_threshold` | — | 0.0~1.0. 높을수록 객체 검출이 엄격 |
| `export_textured_glb` | `true` | `false`면 흰색·무텍스처 메시 |
| `seed` | — | 재현성 |

`sam_3_3d_body`는 별도 파라미터를 쓴다: `export_meshes`, `include_3d_keypoints`, `include_mhr_params` (전부 기본 `true`).

---

## 5. Tripo 계열

`tripo_3d`는 텍스트에서 바로 3D를 만든다(미디어 입력 없음). `tripo_h3_1_image_to_3d`는 이미지 1장 기반이다.

공통 파라미터: `texture`(기본 `true`), `pbr`(기본 `true`, 켜면 텍스처도 함께 켜짐), `texture_quality`·`geometry_quality`(`standard`/`detailed`), `face_limit`(1000~2000000), `auto_size`.

---

## 6. 안티패턴

- **`enable_animation`만 켜기** — `enable_rigging` 없이는 오류다.
- **`texture_prompt`만 넣기** — `should_texture: true` 없이는 무시되거나 오류다.
- **각도 여러 장이 있는데 단일 이미지 모델 사용** — `multi_image_to_3d`가 형상 정확도에서 유리하다.
- **동물·사물에 리깅 기본 적용** — 인간형 전제다. 켜기 전에 알린다.
- **"3D처럼 보이는 그림"에 3D 모델 사용** — 실제 메시가 필요 없고 렌더 이미지만 원하면 이미지 모델이 싸다.
- **`animation_action_id` 추측** — 조회 도구로 확인한다.
