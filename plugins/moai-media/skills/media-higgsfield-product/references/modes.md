# modes.md — 10개 촬영 모드 판정과 프롬프트 구조

> `media-higgsfield-product` | 요청을 모드로 가르는 규칙과, 각 모드가 담아야 할 프롬프트 구성 요소.

**Evidence tier:** 2차 (Higgsfield 공식 스킬 `higgsfield-product-photoshoot` v0.12.0, MIT — 모드 표·판정 규칙·동점 처리)
프롬프트 구성 요소는 그 모드 정의에서 역산한 것으로 **3차(추론)** 이며, 공식 백엔드 강화기와 동일 산출을 보장하지 않는다.

---

## 1. 판정 규칙

**표면 키워드가 아니라 의도로 고른다.** 둘 다 걸리면 더 구체적인 쪽을 택한다.

| 신호 | 모드 |
|---|---|
| 제품 + 중립·깔끔·흰 배경·스튜디오·카탈로그·쇼핑몰 | `product_shot` |
| 제품 + 장면·사용 중·주방·야외·카페·헬스장 | `lifestyle_scene` |
| 손으로 들기·얼굴과 제품·뷰티 도포·시연 | `closeup_product_with_person` |
| 핀터레스트·핀·세로 핀 | `moodboard_pin` |
| 히어로·배너·웹사이트 헤더·랜딩·이메일 헤더·가로형 | `hero_banner` |
| 캐러셀·슬라이드 포스트·다중 슬라이드·넘기는 | `social_carousel` |
| 광고·광고 팩·페이드 소셜·메타/틱톡/핀터레스트 광고 | `ad_creative_pack` |
| 모델 착용·가상 피팅·바디샷·패션 화보·룩북 | `virtual_model_tryout` |
| 부유·플로팅·스플래시·정지된 순간·초현실·CGI·조형 | `conceptual_product` |
| **기존 이미지의** 미감·무드·시즌만 변경 | `restyle` |

---

## 2. 동점 처리

| 요청 | 판정 | 이유 |
|---|---|---|
| "주방 조리대 위 제품의 핀터레스트 핀" | `moodboard_pin` | 플랫폼이 이긴다 |
| "제품 사용 장면을 보여주는 히어로 배너" | `hero_banner` | 포맷(배너)이 이긴다 |
| "여러 장면에 놓인 제품 캐러셀" | `social_carousel` | 다중 슬라이드가 이긴다 |
| "세럼 바르는 사람 클로즈업" | `closeup_product_with_person` | 구체 장르가 이긴다 |

원칙: **플랫폼 > 포맷 > 장르 > 일반 장면.**

---

## 3. 모드별 프롬프트 구성 요소

강화기가 없으므로 아래 요소를 직접 채운다. 공통 골격은 `제품 정체 → 배치·구도 → 조명 → 배경·환경 → 질감·마감 → 용도 규격`.

| 모드 | 반드시 담을 것 | 기본 비율 |
|---|---|---|
| `product_shot` | 중립 배경 색, 그림자 성격(하드/소프트), 제품 정면성, 카탈로그 여백 | `1:1` |
| `lifestyle_scene` | 장소, 시간대·자연광, 주변 소품, 사람 손의 유무, 생활감 | `4:5` |
| `closeup_product_with_person` | 크롭 범위(손/입술/눈가), 피부 질감, 제품 라벨 가독성, 동작 순간 | `4:5` |
| `moodboard_pin` | 세로 여백, 무드 키워드, 팔레트 통일, 상단 시선 유도 | `2:3` |
| `hero_banner` | 좌우 여백(카피 자리), 시선 방향, 가로 확장 구도, 배경 단순화 | `16:9` |
| `social_carousel` | **전 슬라이드 공유 시각 시스템**, 슬라이드별 변주 축, 연결감 | `1:1` 또는 `4:5` |
| `ad_creative_pack` | 훅 요소, 변형 축(앵글·조명·배경), 플랫폼 규격, 여백 안전영역 | 플랫폼별 |
| `virtual_model_tryout` | 모델 아키타입, 환경, 프레이밍(전신/3/4/상반신/제품 클로즈업), 착용 정합 | `4:5` 또는 `3:4` |
| `conceptual_product` | 물리 현상(부유·비산·결빙), 배경 추상도, 조명 드라마, 재질 강조 | `1:1` |
| `restyle` | **보존할 것**과 **바꿀 것**을 분리 명시, 목표 미감, 시즌 맥락 | 원본 유지 |

기본 비율은 출발점이다. 사용자가 명시하면 그쪽을 따르고, 실제 허용 값은 `models_explore`로 확인한다.

---

## 4. 다중 변형 규칙

- 장수를 요청하면 **프리셋·조명·앵글·팔레트**를 서로 다르게 가져간다. 같은 문장을 바꿔 쓴 수준이면 실패다.
- `social_carousel`·`ad_creative_pack`은 장수가 슬라이드/변형 수다. 변형을 주되 **팔레트·타이포·구도 문법은 고정**한다 — 묶음으로 보여야 한다.

---

## 5. 안티패턴

- **핀터레스트 요청에 `product_shot`** — 가장 흔한 오판정이다.
- **10개 밖의 모드 이름 발명** — 표에 있는 것만 쓴다.
- **`restyle`에 보존 항목 미기재** — 무엇을 바꾸지 말아야 하는지 없으면 피사체까지 바뀐다.
- **캐러셀 슬라이드를 각각 따로 설계** — 시각 시스템이 깨진다.
- **조립한 프롬프트 전문을 사용자에게 반환** — 사용자가 원하는 것은 결과 이미지다.
- **제품 사진 없이 텍스트만으로 진행** — 충실도가 크게 떨어진다. 업로드를 먼저 권한다.
