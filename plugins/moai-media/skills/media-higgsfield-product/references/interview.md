# interview.md — 사전 인터뷰 유형 (A~F)

> `media-higgsfield-product` | 사용자 상황별로 무엇을 물을지.
> **한 메시지에 4문항을 넘기지 않는다.** 맥락에서 답이 나온 질문은 건너뛴다. 선택지를 붙여 묻고, 열린 질문을 하지 않는다.

**Evidence tier:** 2차 (Higgsfield 공식 스킬 `higgsfield-product-photoshoot` v0.12.0, MIT)

> 이 스킬은 사용자에게 직접 묻지 않는다. 아래 슬롯을 blocker로 반환하고, 실제 질문은 오케스트레이터가 `AskUserQuestion`으로 진행한다.

---

## 유형 A — 제품 사진 업로드 + "이미지 만들어줘" (용도 미지정)

1. 몇 장? `[1 / 3 / 5]`
2. 스타일·무드? `[깔끔한 스튜디오 / 라이프스타일 / 컨셉추얼 / 모델 착용 / 기타]`
3. 어디에 쓰나? `[쇼핑몰 / 인스타그램 / 핀터레스트 / 유료 광고 / 웹사이트 히어로]`
4. 맞출 브랜드 컬러? (명확하면 생략)

---

## 유형 B — 제품 사진 업로드 + 용도 명시

"광고 소재 만들어줘", "핀터레스트 핀", "히어로 배너" 등. **모드는 이미 정해졌다.** 빈 곳만 묻는다.

1. 몇 장? (다중 산출 모드일 때만)
2. 오퍼·무드·훅은?
3. 특별히 강조할 부분?

---

## 유형 C — 텍스트만, 제품 사진 없음

1. 제품 사진을 올릴 수 있나? **(권장 — 충실도가 크게 올라간다)**
2. 없다면 제품 서술 — 카테고리·패키지·색·특징
3. 스타일? (유형 A와 같은 선택지)
4. 어디에 쓰나?

---

## 유형 D — 기존 이미지 + "다시 / 분위기 바꿔 / 다른 버전"

→ `restyle`

1. 어떤 미감? `[클린걸 / 코티지코어 / 콰이어트 럭셔리 / 다크 아카데미아 / Y2K / 기타]`
2. 시즌 맥락? `[크리스마스 / 발렌타인 / 할로윈 / 블랙프라이데이 / 없음]`
3. 무엇을 지키고 무엇을 바꾸나? (애매할 때만)

3번은 생략하기 쉽지만, 빠지면 피사체까지 바뀌어 돌아온다.

---

## 유형 E — 모델이 착용 (패션·액세서리)

→ `virtual_model_tryout`

1. 모델 아키타입? (브랜드 타깃에 맞춰 2~3개 제시)
2. 환경? `[스튜디오 클린 / 야외 자연광 / 스트리트 / 에디토리얼 / 홈 코지]`
3. 프레이밍? `[전신 / 3/4 / 상반신 / 제품 부위 클로즈업]`

---

## 유형 F — 막연한 요청

"우리 브랜드용으로 뭔가 멋진 거 만들어줘" 류.

1. 어떤 제품·주제?
2. 목표? `[마켓플레이스 판매 / 인지도 / 유료 광고 / 웹사이트 개편]`
3. 참조 이미지를 올릴 수 있나?

답을 받으면 A~E 중 해당 유형으로 돌아간다.

---

## 안티패턴

- **4문항 초과** — 한 메시지 한도다.
- **맥락에 답이 있는데 다시 묻기** — 업로드된 이미지, 직전 대화, 브랜드 메모리를 먼저 확인한다.
- **열린 질문** — "어떤 느낌 원하세요?"보다 선택지가 낫다.
- **유형 D에서 보존 항목 생략** — 가장 잦은 재작업 원인이다.
- **유형 C에서 사진 업로드 권유를 건너뛰기** — 텍스트만은 충실도가 크게 떨어진다.
