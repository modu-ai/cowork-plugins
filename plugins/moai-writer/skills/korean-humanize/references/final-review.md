# 최종 검수 (Final Review) — 윤문본 전달 전 마지막 관문

윤문본이 나왔다고 끝이 아니다. **윤문한 주체가 스스로 매긴 점수는 자기 채점**이고, Phase 4-0의 구조 게이트는 **구조만 볼 뿐 의미를 보지 않는다.** 그 사이에 남는 구멍을 이 단계가 메운다.

이 문서는 [`../SKILL.md`](../SKILL.md) **Phase 7**의 본문이다. 윤문본이 만들어질 때마다 예외 없이 돈다.

## 왜 별도 단계인가 — 두 맹점

**맹점 1 — diff는 diff에 안 남은 변경을 못 본다.** 윤문가가 남긴 변경 기록에만 기대면 각주 이동, 제목 병합, 문단 순서 교체처럼 **기록되지 않은 변경**이 통째로 시야 밖에 놓인다. 그래서 이 단계는 diff가 아니라 **원문과 윤문본 전체를 나란히 놓고 직접 대조**한다.

**맹점 2 — 빈 자리에 없던 주장이 들어온다.** 구조 편집을 세게 하면(대구 해체, 빈 수사 제거) 비어버린 자리를 **원문에 없던 단정**이 채우는 부작용이 생긴다. `이는 중요하다`를 지우면서 `이는 시장을 재편할 것이다`를 만들어 넣는 식이다. 앞의 것은 빈 수사이고 뒤의 것은 **없던 주장**이다 — 문장은 자연스러워졌는데 글이 거짓이 됐다.

> **[철칙] 전체 재작성 금지.** 이 단계는 **검증 + 국소 보정**이다. 윤문본을 다시 쓰지 않는다. 전역 재작성 패스가 바로 맹점 2를 만든다. 문제 구간만 최소 수술한다.

## 입력

| 무엇 | 어디 | 필수 |
|---|---|---|
| **원문** | `_workspace/{run_id}/01_input.txt` | 필수 — 의미 대조의 기준 |
| **윤문본** | `_workspace/{run_id}/final.md` | 필수 |
| 게이트 결과 | Phase 4-0 `verify_gates.py` 출력 | 필수 — 이미 나온 값을 다시 계산하지 않는다 |
| 진단 | 탐지 단계가 무엇을 겨냥했는지 | 선택 — 없어도 진행한다 |

진단이 없다고 중단하지 않는다. 진단은 "무엇을 겨냥했는지"를 알려줄 뿐이고, 이 단계의 본체(의미 보존 + 자연성)는 **원문↔윤문본 직접 대조만으로 성립**한다.

## 1단계 — 의미 보존 15항

원문과 윤문본을 **문단 단위로 나란히** 대조한다. 위반이 보이면 그 구간만 원문 의미로 되돌린다.

| # | 항목 |
|---|---|
| 1 | 사실·주장·수치·날짜·고유명사·인용문과 **핵심 내용 명사·개념어** 100% 보존. 조사·어미 변화는 허용하되, 원형 내용 어휘가 사라졌으면 복원 |
| 2 | 원문에 있던 정보가 누락되지 않았는가 |
| 3 | **없던 주장이 주입되지 않았는가** ★ — 윤문본의 각 단정이 원문에 근거가 있는가. 빈 수사를 지운 자리에 새 단정이 들어오지 않았는가 |
| 4 | 인과·조건·시간 순서 보존 |
| 5 | 큰따옴표 인용 내부 불변 |
| 6 | 법률 조문·학술 개념어 원형 |
| 7 | 수치의 단위가 바뀌지 않았는가 (억/조, %, 배수) |
| 8 | 부정·긍정이 뒤집히지 않았는가 |
| 9 | 주어와 대상의 관계가 유지됐는가 (누가 누구에게 무엇을) |
| 10 | 한정사 범위 보존 — `일부`가 `대부분`으로, `가능성`이 `확정`으로 넓어지지 않았는가 |
| 11 | 예시가 보존됐는가 (삭제·교체·일반화되지 않았는가) |
| 12 | 논리 연결어의 의미 보존 — `그러나`를 `그리고`로 바꾸면 논리가 바뀐다 |
| 13 | **확신도(톤 극성) 보존** — 원문의 hedging이 단정으로, 단정이 hedging으로 바뀌지 않았는가 |
| 14 | **각주 원위치·원번호·개수·정의 보존** ★ — 각주 이동은 인용 출처 변조이며 사실 왜곡이다 |
| 15 | **제목·소제목·번호 매김 줄의 독립성** ★ — 본문에 병합되지 않았는가 |

★ 표시 3항(3·14·15)은 diff에 잘 남지 않아 놓치기 쉬운 항목이다. 의식적으로 본다.

**위반 처리**: 해당 구간을 **원문 의미로 국소 롤백**. 국소 보정으로 해결되지 않을 만큼 훼손됐으면 억지로 재작성하지 말고 `사람 검토 요청`으로 판정한다.

## 2단계 — 자연성 양방향

**한 방향만 보면 반드시 반대쪽으로 넘어간다.** 잔존만 보면 과윤문이 쌓이고, 과윤문만 보면 AI 티가 남는다.

### (a) 잔존 — 겨냥한 것이 실제로 완화됐는가

탐지 단계가 지목한 지배 패턴이 윤문본에서 실제로 줄었는가. 안 줄었으면 **그 구간만** 추가 윤문한다.

특히 확인: `C-8` 대구(실측 최강 신호) · `C-11` 연결어미 뒤 쉼표 · `D-1` 결산 lexicon · `C-5` 이모지.

### (b) 과윤문 — 사람 글을 지우지 않았는가 (역방향)

아래 셋은 **각각 단독으로도** 플래그다. 두 개가 겹쳐야 하는 조건이 아니다.

| 유형 | 신호 | 처리 |
|---|---|---|
| **격식 상향** | 원문에 없던 `-하였-` 출현. 구어 종결(`~인데요 / ~거든요 / ~한 겁니다`) 소실 | 롤백 — 살아있는 구어는 사람 글의 증거다 |
| **상투구 주입** | 원문에 없던 D 계열 관용구 출현 (`기록적인 성과를 거두었다` · `괄목할 만한` · `~로 평가된다` · `주목받았다`) | 제거 — 윤문이 아니라 역주행이다 |
| **문학화** | 원문에 없던 비유·수사가 새로 생김 | 제거 — 장르 이탈이다 |

### (c) 실증 교정 4건이 지켜졌는가 ★

**정상 한국어를 지우지 않았는지** 확인하는 항목이다. 근거: [`empirical-validation.md`](empirical-validation.md)

- `A-2 ~를 통해` — 한두 번 남은 것을 지우지 않았는가 (원어민이 번역가보다 2배 더 쓴다)
- `A-16 대명사` — **영어 원문이 없는 자생 한국어 산문**에서 `그/그녀`를 지우지 않았는가
- `I-1 ~것이다` — 연속 3회 미만인데 평서화하지 않았는가 (사람이 2배 더 쓴다)
- `E-1 장문` — 장문을 만든다며 **원문에 없던 내용을 덧붙이지** 않았는가

## 3단계 — 게이트 재확인

Phase 4-0 게이트 결과를 다시 읽는다. **보정을 했다면 게이트를 한 번 더 돌린다** — 보정 자체가 변경률을 움직이기 때문이다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/korean-humanize/references/verify_gates.py" \
  --before "_workspace/{run_id}/01_input.txt" \
  --after  "_workspace/{run_id}/final.md" \
  --genre {장르}
```

- exit 2가 다시 나오면 **윤문본을 채택하지 않는다.**
- P2(대구 전멸)가 FAIL이면 하나를 되살린다 — 전량 삭제는 처방이 아니다.

## 4단계 — 판정

| 판정 | 조건 | 후속 |
|---|---|---|
| **accept** | 보정 없이 전 항목 통과 | 전달 |
| **corrected** | 국소 보정 후 통과 | 전달 + **무엇을 되돌렸는지 고지** |
| **hold_and_report** | 국소 보정으로 해결되지 않는 의미 위반, 또는 게이트 exit 2 재발 | **전달하지 않는다.** 원문·윤문본·문제 구간을 함께 사람에게 넘긴다 |

**[철칙] 검수 없이 전달하지 않는다.** 어떤 이유로든 이 단계를 건너뛰었다면, 건너뛰었다는 사실과 이유를 결과에 **명시**한다. 조용히 생략하면 검수가 있었는지 없었는지 아무도 모른다.

### 보고 형식

```
최종 검수: {accept | corrected | hold_and_report}
  의미 보존 15항: 통과 | 위반 {n}건 → {되돌린 내용}
  자연성 잔존   : {완화된 패턴} | 잔존 {id}
  과윤문        : 없음 | {유형} {n}건 → 되돌림
  게이트 재확인 : exit {0|1|2}
```

## 선택 경로 — codex 적대적 감사

`mcp__moai__codex_*` 도구를 **쓸 수 있는 환경에서만** 위 4단계 위에 얹는 추가 경로다.

- **필수가 아니다.** codex는 이 마켓플레이스가 배포하는 구성 요소가 아니며, 일반 사용자 환경에는 없다. 위 1~4단계가 codex 없이 성립하도록 설계돼 있다.
- 쓸 수 있으면: `mcp__moai__codex_audit(mode="adversarial")`로 원문↔윤문본 대조를 한 번 더 받는다. **file:line 근거가 붙은 구체 결함만** 반영하고, 문체 취향 의견은 반영하지 않는다.
- codex가 없거나 실패하면 **조용히 넘어가지 않는다** — "codex 감사 미실행"을 결과에 적는다.

## 이 단계가 하지 않는 것

- **전체 재작성** — 검증과 국소 보정만 한다
- **없는 정보 보강** — 원문이 모호하면 모호한 채로 둔다
- **등급 재산정** — 등급은 Phase 5의 몫이다
- **의미 판정의 외주화** — 게이트가 전 축을 통과했다는 것은 "구조가 온전하다"이지 "의미가 보존됐다"가 아니다. 그 판정은 이 단계가 사람의 눈으로 한다
