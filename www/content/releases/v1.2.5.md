**릴리스 날짜**: 2026-09-03
**버전**: v1.2.5 (최신)
**업데이트 방법**: 두 데스크톱 앱 모두 **플러그인(Plugins) 메뉴 → 해당 코워커 → Update**. 화면별 위치는 [플러그인 설치와 관리](/plugins/install/) 4절에 정리해 두었습니다.

## 하이라이트

이번 릴리스는 **넣어 둔 API 키가 코워커에게 닿지 않던 문제**를 고치는 작업입니다.

스마트스토어나 전자공시처럼 바깥 서비스에 직접 접속하는 코워커는 그 서비스의 API 키가 있어야 일합니다. 그런데 키를 넣어 두어도 코워커는 그 키를 받지 못하고, 키 이름이 적힌 문자열을 대신 받고 있었습니다. 코워커는 정상으로 뜨고 도구 목록도 멀쩡히 보이는데 막상 시키면 인증에 실패했습니다. 어디가 잘못됐는지 화면 어디에도 나오지 않았습니다.

- **Claude Cowork에서 키 입력창이 뜹니다.** 키가 필요한 코워커를 켜면 앱이 항목을 물어보고, 비밀 항목은 가려서 받아 안전한 곳에 보관합니다.
- **ChatGPT Work에서 셀러·스레드 코워커의 연결 도구가 뜹니다.** 이 앱에서는 아예 뜨지 못하던 통로였습니다.
- **키를 파일 하나에 적어 두면 두 앱이 같이 씁니다.** 앱마다 따로 넣지 않으셔도 됩니다.
- **[API 키 넣는 법](/plugins/mcp/credentials/)** 문서를 새로 썼습니다. 서비스별 항목 이름과 안전 수칙을 한자리에 모았습니다.

## 고친 것

### 넣어 둔 키가 코워커에게 닿습니다

지금까지 키는 코워커 설정에 적어 두는 방식이었습니다. 그 설정이 실제로 값으로 바뀌어 코워커에게 전달되는지는 아무도 확인하지 않았고, 확인해 보니 **데스크톱 앱에서는 바뀌지 않았습니다.** 코워커는 값 대신 항목 이름이 적힌 문자열을 그대로 받았습니다.

이제 코워커는 값을 세 곳에서 차례로 찾습니다. 앱이 넘겨준 값이 있으면 그것을 쓰고, 없으면 자격증명 파일을 보고, 그래도 없으면 "키가 설정되지 않았습니다"라고 알려 드립니다. **바뀌지 않은 문자열은 값이 아닌 것으로 판정**하므로, 예전처럼 잘못된 키로 계속 두드리는 일이 없습니다.

영향받는 코워커: 셀러(스마트스토어·아임웹·카페24), 스레드 발행, 재무세무·데이터 애널리스트·코워커(전자공시), 미디어(ElevenLabs), 법무(국가법령정보).

### 키 입력창이 생겼습니다 — Claude Cowork

키가 필요한 코워커를 켜면 앱이 **입력 폼**을 띄웁니다. 항목마다 무엇을 넣는 자리인지 설명이 붙고, 어디서 발급받는지도 적어 두었습니다. 비밀 항목은 입력할 때 가려지고 앱이 안전한 곳(맥 키체인 등)에 보관하므로, 채팅 기록에도 파일에도 남지 않습니다.

나중에 바꾸시려면 코워커 설정 화면에서 다시 입력하시면 됩니다.

### 자격증명 파일 — 두 앱 공통

ChatGPT Work에는 아직 이런 입력 폼이 없습니다. 그래서 코워커들이 **파일에서도 키를 읽도록** 만들었습니다.

```
~/.moai/mcp/<서비스이름>.json
```

**직접 만들지 않으셔도 됩니다.** 코워커에게 "전자공시 키 넣어 줘" 하고 키를 알려 주시면 파일을 대신 만들어 드립니다. 형식과 서비스별 항목 이름은 [API 키 넣는 법](/plugins/mcp/credentials/)에 적어 두었습니다.

같은 컴퓨터에서 두 방법을 같이 쓰셔도 됩니다. 코워커는 앱이 넘겨준 값을 먼저 쓰고, 없을 때 파일을 봅니다.

### ChatGPT Work에서 셀러·스레드 코워커가 실제로 뜹니다

셀러와 스레드 발행 코워커의 연결 도구는 ChatGPT Work에서 아예 뜨지 못했습니다. 코워커가 자기 설치 위치를 찾는 방식이 Claude Cowork 전용이라, 다른 앱에서는 있지도 않은 폴더를 열려다 곧바로 멈췄습니다.

두 앱이 각자의 방식으로 위치를 찾도록 배선을 나눴습니다. ChatGPT Work가 쓰는 실행기로 실제 세션을 띄워 세 통로가 모두 올라오는 것까지 확인했습니다. 다만 앱 화면에서 직접 눌러 본 것은 아닙니다.

전자공시와 ElevenLabs도 같은 이유로 ChatGPT Work에서 키를 받지 못하고 있었습니다. 이쪽은 코워커를 대신 띄워 주는 작은 도우미를 앞에 세워 해결했습니다.

### 코워커 목록 정리

다섯 코워커(커리어코치·컨설턴트·CS매니저·인사채용·튜터)가 **있지도 않은 연결 통로를 쓴다고 적어 두고** 있었습니다. 이 코워커들은 원래 바깥 서비스에 접속하지 않습니다. 잘못 적힌 항목을 지웠습니다.

아울러 코워커 소개 파일에서 ChatGPT Work가 받아들이지 않는 항목 두 개를 걷어냈습니다. 지금은 문제없이 설치되지만 앞으로 검사가 엄격해지면 한꺼번에 막힐 수 있는 자리였습니다.

## 알아 두실 것

**법무 코워커의 국가법령정보 조회는 Claude Cowork에서만 됩니다.** 이 통로는 키가 접속 주소 자체에 들어가는 구조라, ChatGPT Work에서는 대신 넣어 줄 방법이 없습니다. 되는 것처럼 보이면서 안 되는 상태보다 낫다고 판단해 ChatGPT Work 쪽 목록에서는 뺐습니다. 계약 검토·NDA 트리아지·특허 검색 같은 법무 코워커의 다른 일은 두 앱에서 그대로 하실 수 있습니다.

**Windows에서는 아직 실제 기기로 확인하지 못했습니다.** 윈도우에서 깨지는 형태(전용 명령, 셸 연산자, 고정 경로)는 전부 걷어냈고 문서 점검도 통과했지만 실제 윈도우 컴퓨터에서 돌려 본 것은 아닙니다. 문제가 있으면 알려 주세요.

## 개발자를 위한 메모

- 자격증명 해석은 공유 코어의 `credentials.py`가 담당합니다. 순서는 환경변수 → `~/.moai/mcp/<서비스>.json` → 기본값입니다. 바뀌지 않은 `${...}` 자리표시자와 빈 문자열은 '값 없음'으로 판정합니다.
- 제3자 연결 도구는 `mcp-launch` 런처를 거칩니다. 의존성 없이 실행되며, 환경변수를 채운 뒤 원래 서버를 대체 실행합니다.
- `scripts/check-plugin-runtimes.py`가 두 앱의 배선 정합, 자리표시자 잔류, 윈도우 금지 패턴, 입력 항목 대응, 런처 사본 드리프트를 한 번에 검사합니다.

## 업데이트 방법

두 데스크톱 앱 모두 **Plugins 메뉴 → 해당 코워커 → Update**입니다. 이번 릴리스는 코워커 전체가 올라갔으니 쓰시는 코워커를 모두 업데이트해 주세요.

업데이트 후 대화를 새로 시작하시면 새 배선이 적용됩니다. 키가 필요한 코워커라면 이때 입력창이 뜹니다.
