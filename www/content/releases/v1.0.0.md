**릴리스 날짜**: 2026-07-31
**버전**: v1.0.0
**업데이트 방법**: 두 데스크톱 앱 모두 **플러그인(Plugins) 메뉴 → 해당 코워커 → Update**. 터미널을 쓴다면 [플러그인 설치와 관리](/plugins/install/) 4절을 참고하세요.

## 하이라이트

**모두의 코워크가 v1.0.0에서 새로 출발합니다.** 버전 번호를 `moai-cowork` 기준으로 다시 세우고, 플러그인 17종을 모두 같은 자리(1.0.0)에 놓았습니다.

이전에는 플러그인 하나만 고쳐도 전체 번호가 함께 올라갔습니다. 그래서 `moai-coworker`는 6.1.1까지 간 반면 대부분은 0.1.x에 머물러, 번호만 보고는 무엇이 얼마나 바뀌었는지 알 수 없었습니다. 이제는 **고친 플러그인의 번호만 올라갑니다.**

## 새 버전 규칙

| 대상 | 시작 | 언제 올라가나 |
|---|---|---|
| moai-cowork (마켓플레이스·문서) | 1.0.0 | 사이트·문서·마켓플레이스 구조 자체가 바뀔 때. 플러그인 변경과는 무관합니다 |
| 플러그인 17종 | 1.0.0 | 그 플러그인이 수정될 때만. 손대지 않으면 1.0.0 그대로입니다 |
| 스킬 213종 | 1.0.0 | 그 스킬이 수정될 때 |

세 자리는 각각 `MAJOR.MINOR.PATCH`이며, 각 자리는 100을 넘기지 않습니다. PATCH가 100에 닿으면 MINOR를 올리고 PATCH를 0으로 되돌립니다.

## 사용자가 해야 할 일

없습니다. 버전 번호 체계만 바뀌었고 **스킬·기능·사용법은 그대로**입니다.

이미 설치해 두셨다면 최신 상태로 갱신해 두세요. 두 데스크톱 앱 모두 **플러그인(Plugins) 메뉴**에서 코워커 카드의 **Update** 버튼을 누르면 됩니다.

터미널이 익숙하다면 Claude Cowork에서:

```bash
claude plugin marketplace update moai-cowork
claude plugin update <코워커 이름>@moai-cowork
```

ChatGPT Work의 터미널 명령은 [플러그인 설치와 관리](/plugins/install/) 4절에 정리해 두었습니다.
