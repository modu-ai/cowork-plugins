## 하이라이트

**직접 만든 연결 도구(MCP) 이름을 `moai-mcp-` 로 통일했습니다.** 공유 코어가 `moai-mcp-core` 라서, 코어와 서버가 한 계열로 읽히도록 맞췄습니다. 그리고 **유튜브 연결이 실제로 되는지 확인하는 명령**을 추가했습니다.

## 이름이 이렇게 바뀝니다

| 이전 | 지금 |
|---|---|
| `moai-youtube` | `moai-mcp-youtube` |
| `moai-smartstore` | `moai-mcp-smartstore` |
| `moai-imweb` | `moai-mcp-imweb` |
| `moai-cafe24` | `moai-mcp-cafe24` |
| `moai-threads-poster` | `moai-mcp-threads-poster` |

이름 하나만 바뀐 게 아니라 폴더·실행 이름·내부 모듈까지 **다섯 자리를 같은 문자열로** 맞췄습니다. 예전에는 `moai-youtube`(서버) / `moai-youtube-mcp`(실행) / `moai_youtube`(내부)처럼 조금씩 달라서, 어디를 고쳐야 하는지 매번 헷갈렸습니다.

{{< hint type="note" >}}
**하실 일은 없습니다.** 설정 파일이 플러그인에 함께 들어 있어 업데이트하면 같이 바뀝니다. **자격증명(API 키·토큰)도 그대로**입니다 — 환경변수 이름은 하나도 바뀌지 않았습니다.
{{< /hint >}}

다른 개발자가 만든 연결 도구(Higgsfield·ElevenLabs·국가법령정보 등)는 **이름을 바꾸지 않았습니다.** 바꾸면 그게 어디서 왔는지 알 수 없게 되니까요.

## 유튜브 연결 확인 명령

자격증명을 넣고 나서 "이게 제대로 된 건가?" 싶을 때, **터미널에서 한 번 불러 보고 확인**할 수 있습니다.

```
cd <플러그인경로>/mcp-servers/moai-mcp-youtube
uv run python -m moai_mcp_youtube.selftest
```

읽기만 하고 아무것도 바꾸지 않습니다. 채널 이름과 최근 영상 제목이 나오면 성공입니다.

좋은 점은 **어디서 막혔는지 알려 준다**는 것입니다. 토큰 발급에서 멈추면 동의 절차 문제, 채널 조회에서 403이 나오면 API가 꺼져 있거나 권한이 부족한 것 — 이렇게 단계별로 원인을 짚어 줍니다. Claude에 붙여 놓고 "왜 안 되지?" 하며 헤매는 것보다 훨씬 빠릅니다.

자세한 내용은 [유튜브 연동](../../plugins/mcp/youtube/)에 있습니다.

## 업데이트하면 되나요

**됩니다.** 이름이 바뀐 것은 내부 구조라, 쓰시던 방식 그대로입니다. 자격증명을 다시 넣을 필요도 없습니다.
