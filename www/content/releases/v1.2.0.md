**릴리스 날짜**: 2026-08-08
**버전**: v1.2.0
**업데이트 명령**: Claude Cowork `/plugin marketplace update moai-cowork`, ChatGPT Work `codex plugin marketplace upgrade` 또는 `codex plugin add moai-cowork`

## 하이라이트

**유튜버 코워커가 합류했습니다.** 유튜브 채널을 굴리는 데 실제로 시간이 드는 일 — 라이브 방송 준비와 진행, 촬영 세팅 점검, 편집 지시서, 썸네일·제목 패키징, 업로드와 설명란·챕터, 성과 리뷰, 댓글 응대, 롱폼에서 쇼츠 뽑기 — 을 맡습니다.

기존 마케터의 유튜브 기획 스킬과 겹치지 않게 경계를 그었습니다. **무엇을 만들지 정하는 일은 마케터, 만들고 올리고 굴리는 일은 유튜버, 화면·소리를 실제로 생성하는 일은 미디어 크리에이터**입니다. `/project`로 초기화하면 이 셋이 하나의 작업 흐름으로 이어집니다.

## 새 코워커 — 유튜버

| 스킬 | 하는 일 |
|---|---|
| `youtube-channel-ops` | 업로드 리듬·시리즈 포트폴리오·분기 목표 |
| `youtube-live-ops` | 라이브 방송 전 점검 · 큐시트 · 실시간 채팅 · 다시보기 정리 |
| `youtube-production` | 촬영 세팅 점검 · 확보할 컷 목록 · 편집 지시서 |

| `youtube-publish-ops` | 업로드 · 설명란 · 챕터 · 재생목록 · 자막 · 예약 발행 |
| `youtube-analytics-review` | 어느 단계에서 새는지 특정 → 다음 액션 하나 |

자세한 소개는 [유튜버 코워커 페이지](../../moai-agents/youtuber/)를 보세요.

### 유튜브 연동은 준비 중입니다

{{< hint type="note" >}}
이 릴리스 시점의 기록입니다. 유튜브 연동은 [v1.3.0](../v1.3.0/)에서 완성됐습니다.
{{< /hint >}}

유튜브에는 Google이 관리하는 공식 MCP 서버가 없습니다. 그래서 Data API v3 · Live Streaming API · Analytics API를 감싼 자체 서버를 준비하고 있습니다. **연결 전에도 스킬은 그대로 작동합니다** — 점검표·큐시트·편집 지시서·설명란 원고·답글 초안까지 만들어 드리고, 실제 버튼을 누르는 단계는 유튜브 스튜디오에서 하실 수 있도록 순서를 안내합니다.

## 오픈소스 크레딧 페이지 신설

모두의 코워크가 어깨를 빌린 프로젝트를 한 페이지에 모았습니다 — 스킬이 참고한 방법론, 함께 쓰는 제3자 MCP 서버, 자체 MCP 서버가 쓰는 라이브러리, 이 문서 사이트를 떠받치는 도구까지.

저장소 `NOTICE` 파일에 흩어져 있던 고지와, 릴리스 기록에만 남아 있던 출처를 한자리에 정리했습니다. 지금은 사라진 스킬의 출처도 남겼습니다 — 기록이 없어지면 나중에 같은 자리를 다시 만들 때 출처를 잃기 때문입니다.

[오픈소스 크레딧](../../plugins/open-source/)에서 보실 수 있습니다. 빠진 것이나 잘못 적힌 것이 있으면 알려 주세요.

## 내부 정비

**자체 제작 MCP 서버 이름을 통일했습니다.** 우리가 직접 만든 서버는 `moai-` 접두어로 맞추고, 제3자 서버는 원저작자의 이름을 그대로 둡니다 — 이름을 바꾸면 출처를 알 수 없게 되니까요. SNS 크리에이터의 서버 경로와 실행 이름이 이 규칙에 맞게 정리됐습니다. 사용자가 하실 일은 없습니다.

**모든 산출물이 네 조합에서 동일하게 동작하도록** 기준을 문서화했습니다 — macOS와 Windows, Claude Cowork(데스크톱)와 ChatGPT Work. 서버 실행 명령에서 특정 운영체제에만 있는 셸을 쓰지 않고, 경로 조립 방식도 통일했습니다.

## 업데이트하면 되나요

**됩니다. 기존 사용에 영향이 없습니다.** 새 코워커가 추가되고 문서가 늘었을 뿐, 기존 스킬의 사용법은 그대로입니다.

유튜브 작업을 하실 분은 업데이트 후 `/project`로 프로젝트를 다시 초기화하거나 `/project update`를 실행하면, 유튜버가 포함된 작업 흐름이 프로젝트 지침에 반영됩니다.
