**릴리스 날짜**: 2026-08-08
**버전**: v1.2.0 (최신)
**업데이트 명령**: Claude Cowork `/plugin marketplace update moai-cowork`, ChatGPT Work `codex plugin marketplace upgrade` 또는 `codex plugin add moai-cowork`

## 하이라이트

이번 릴리스는 **투명성과 정리**입니다. 새 기능보다는, 지금 있는 것을 더 잘 알 수 있게 만드는 데 집중했습니다.

- 모두의 코워크가 어깨를 빌린 오픈소스를 한 페이지에 모았습니다.
- MCP(외부 서비스 연결)가 무엇이고 어떻게 붙이는지 안내 섹션을 열었습니다.
- 직접 만든 연결 도구의 이름을 `moai-mcp-` 로 통일했습니다.

## 오픈소스 크레딧 페이지 신설

스킬이 참고한 방법론, 함께 쓰는 제3자 MCP 서버, 자체 서버가 쓰는 라이브러리, 이 문서 사이트를 떠받치는 도구까지 — 빌린 것을 전부 적었습니다.

저장소 `NOTICE` 파일에 흩어져 있던 고지와, 릴리스 기록에만 남아 있던 출처를 한자리에 정리했습니다. **지금은 사라진 스킬의 출처도 남겼습니다** — 기록이 없어지면 나중에 같은 자리를 다시 만들 때 출처를 잃기 때문입니다.

[오픈소스 크레딧](../../plugins/open-source/)에서 보실 수 있습니다. 빠진 것이나 잘못 적힌 것이 있으면 알려 주세요.

## 연결 도구 이름 통일

직접 만든 연결 도구를 `moai-mcp-` 로 맞췄습니다.

| 이전 | 지금 |
|---|---|
| `moai-smartstore` | `moai-mcp-smartstore` |
| `moai-imweb` | `moai-mcp-imweb` |
| `moai-cafe24` | `moai-mcp-cafe24` |
| `moai-threads-poster` | `moai-mcp-threads-poster` |

이름 하나만이 아니라 폴더·실행 이름·내부 구조까지 **다섯 자리를 같은 문자열로** 맞췄습니다. 예전에는 자리마다 조금씩 달라서 어디를 고쳐야 하는지 매번 헷갈렸습니다.

{{< hint type="note" >}}
**하실 일은 없습니다.** 설정 파일이 플러그인에 함께 들어 있어 업데이트하면 같이 바뀝니다. **자격증명(API 키·토큰)도 그대로**입니다 — 환경변수 이름은 하나도 바뀌지 않았습니다.
{{< /hint >}}

다른 개발자가 만든 연결 도구(Higgsfield·ElevenLabs·국가법령정보 등)는 **이름을 바꾸지 않았습니다.** 바꾸면 그게 어디서 왔는지 알 수 없게 되니까요.

## 내부 정비

연동 서버들이 각자 복제하고 있던 인증·토큰 저장·재시도 코드를 **공통 코어로 모았습니다.** 아임웹과 카페24가 이 코어를 쓰도록 옮겼고, 옮기는 김에 카페24에는 없던 테스트도 만들었습니다.

스마트스토어와 Threads는 **일부러 옮기지 않았습니다.** 인증 방식이 근본적으로 달라서, 억지로 맞추려면 쓰는 곳이 하나뿐인 코드를 공통 코어에 넣어야 합니다. 그건 공통화가 아니라 군더더기입니다. 두 서버는 지금 잘 동작하고 있으니 그대로 둡니다.

**모든 산출물이 네 조합에서 동일하게 동작하도록** 기준도 문서화했습니다 — macOS와 Windows, Claude Cowork(데스크톱)와 ChatGPT Work. 서버 실행 명령에서 특정 운영체제에만 있는 셸을 쓰지 않고, 경로 조립 방식도 통일했습니다.

## 업데이트하면 되나요

**됩니다. 기존 사용에 영향이 없습니다.** 쓰시던 방식 그대로이고, 자격증명을 다시 넣을 필요도 없습니다.
